Design calls (the spec fixes none of them):

1. Exit code rule (W-C6): `claude::run` and `opencode::run` return `Launcher::run(..).code`. `LaunchOutcome.code` is the integer that `Launcher::run` returns today on every path, so a launch outside a workspace has the same exit code as today.
2. `received` is read while the signal handling is still installed, after the cleanup. A launch that ends before `install` (exit 11, 12 at `:165`, 13 at `:190`, 2, 1) has `received = false`. The flag is cleared only by the first `install` (the branch that resets `PENDING`), because concurrent launches in one process share the handling.
3. Windows: `signal` is always `None` and `received` is always `false` (the console routine `keep` does not set the flag). Only two items are `cfg(unix)`: the `RECEIVED.store(true, ..)` line (it is in `handle`, which is `cfg(unix)`) and the unix branch of `signal_of`.
4. The callback runs directly after the `Finish` guard is made (`:319`) and before the team file write (`:320`). A callback error goes to the session log only, as the one line `session callback: <text>`, where `<text>` is `zygo_plugins::check::esc(&format!("{e:#}"))`. Nothing goes to stderr.
5. `ZYGO_WORKSPACE` and `ZYGO_PANE` are removed by the env filter (a second name list beside `EXACT`), so the Windows case rule and the `env: removed ...` log line apply. A member launch puts both names in `set`, and `set` wins.
6. `resume_note` without `member` is not written (`SessionView.workspace` stays `None`).
7. `LaunchOutcome` derives `Debug, Clone, Copy, PartialEq, Eq` (the tests compare it).
8. This node adds no wait and no lock; the 5 s bound applies to the callback body, which M2 writes.

/// How a launch ended (workspaces design AU34, AU60, AU73).
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct LaunchOutcome {
    /// The process exit code: the agent's own code when it ran; `128 + n` when signal n ended it or stopped the launch.
    pub code: i32,
    /// The signal that ended the agent; `None` for an exit with a code and on every non-unix target.
    pub signal: Option<i32>,
    /// The agent process was started.
    pub spawned: bool,
    /// The launcher received SIGTERM or SIGHUP between the start of its signal handling and the end of its cleanup.
    pub received: bool,
}

/// What a launch records for its outcome besides the code.
#[derive(Default)]
struct Marks {
    signal: Cell<Option<i32>>,
    spawned: Cell<bool>,
    received: Cell<bool>,
}

/// The signal handling of one launch. Its drop copies `signals::received()` into the marks; the handling ends after that.
struct Handling<'a> {
    marks: &'a Marks,
    _installed: signals::Installed,
}

/// The signal that ended the child; `None` for an exit with a code and on every non-unix target.
fn signal_of(st: ExitStatus) -> Option<i32>
