### Decisions

Each decision is the author's call. D27-D34 and the changes to D3, D12, D14, D17, D18, D20 and D25 are the coordinator's calls from the plan review (B1-B3, M1-M11), recorded here.

- D1. `preflight` runs W§8.1 step 2, step 3 and the id. A state from a newer zygo gives `Err(Exit { code: 1, message: "zygo: workspace state is from a newer zygo; run zygo update" })` (AU29; `--reset` never removes it). A state that does not parse or fails AU84 gives `Ok(Target { state: Err(<StateError text, which names the file>), .. })`, so `up --reset` can rename it and `down` (W10) exits 1 with it (D28). Another read error gives `Err(Exit { code: 1, message: "zygo: <error>" })`.
- D2. Output. Only `zygo: <name> is up` and the AU100 attach line go to `out`; every other line goes to `err`. `up`, `attach` and `repair` never call `process::exit`.
- D3. Texts that the spec does not fix (each one line, `<x>` as in the spec):
  - older tmux: `zygo: tmux <major>.<minor> is too old; workspaces need tmux 3.2 or later`; no tmux: `zygo: workspaces need tmux; install tmux 3.2 or later` (W§8.1 step 2 text with the `zygo: ` prefix); an unreadable version: `zygo: cannot read the tmux version: <error>`
  - name not found (AU20): `zygo: no workspace named <esc(name)>`, exit 1
  - a tmux error that stops `up` or `attach`: `zygo: tmux: <error>`, exit 1
  - AU62: `zygo: tmux socket <path> is not private: the socket and its folder must be yours and the folder must have mode 0700`, exit 1
  - AU37 list: `zygo: --reset drops <kind> agent session <id> (pane <key>)`
  - AU70: `zygo: pane <key>: <kind> agent session <id> resumes with <flags joined by ", ">`
  - AU96 for a pane with no agent session: `zygo: pane <key> not built (no space)`
  - layout refused: `zygo: window <index>: layout <layout:?> refused (<error>); using tiled`
  - AU64 new server: `zygo: started a new tmux server from inside a zygo agent; its panes have no provider keys from the environment`
  - `--loadout` without `--reset` on a saved layout: `zygo: --loadout applies only with --reset or to a new workspace; restoring the saved layout`
  - a refused window value (D31): `zygo: window <index>: name <name:?> refused: window name holds a control character` and `zygo: window <index>: size <w>x<h> is outside 1..=10000`, exit 1; `<index>` is the saved index, or the loadout ordinal
  - a loadout warning (`branch:` not found): `zygo: <warning>`; a `LoadoutError`: `zygo: <error>`, exit 2 for `Unknown` (usage), exit 1 for the others
- D4. Bare repository (AU77). `checkout(cwd)` is `None`: `up` runs `identity::worktrees(&Checkout { top: cwd, common_dir: cwd, main_root: cwd, deadline })`. A non-empty list with no main worktree: exit 2, AU77 text. A main worktree: `checkout(<its path>)` gives the checkout. An error, an empty list or a second `None`: exit 2, AU25 text.
- D5. `up <name>` matches `name` against the readable states of `list_all` (AU20). The target then takes `common_dir` and `main_root` from the state, and `worktrees` from `identity::worktrees` on `main_root` (an error gives an empty list: only `branch:` panes of a `--reset` use it). The name of a new workspace is `unique_name(slug(<main worktree folder name>), taken)`, where `taken` holds the names of the other readable states.
- D6. Window names. W7 adds `Multiplexer::rename_window` (finding 1). `up` renames the first window after `new_session` when it has a name. `new_window` calls `rename_window`, so the code is shared. An empty name counts as no name.
- D7. Loadout size (AU96). A loadout window is created at 200×50 (`LOADOUT_SIZE`). The library has no terminal and no client to read. After the build, the first window's `window-size` is unset and the later windows never had it set, so every window follows the client that attaches. Controller item C6.
