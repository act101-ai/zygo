### Decisions

Author's calls of 2026-11-22 that implement the accepted design; none adds a rule.

- D1. State per plugin instance: `kind: Map<id, "top" | "child">`, `act: Map<id, number>`, the counter `n`, `main`, `mainAct`, `sent` (the id of the last `session` call with an id), `inTurn: Set<id>`. `idleNow` and `children` go.
- D2. Load. In the factory, after `ws` is defined and when `member` is true: `ws("session", {})`, so the first queued call is `session` with stdin `{"cwd": <directory>}`. The factory runs only in a spawned agent, so this call proves the spawn (AU92 through H1).
- D3. Order inside one event, decided before any wait (the design's steps 1-4): (1) classify: a `session.*` event whose `properties.info` is an object with a non-empty string `id` sets `kind[info.id]` to `"child"` when `info.parentID` is truthy, else `"top"`, only when `kind` has no value for it; a new `"child"` leaves the turn set (D4); (2) activate: `session.created` sets `act[info.id] = ++n`; a `session.status` `busy` sets `act[id] = ++n` for the event's session id; (3) turn set (D4); (4) main (D5) for the event's session id and for `info.id`.
- D4. Turn set. A `busy` of a session id that is not a known child and not in `inTurn` adds it; when the set was empty, `ws("prompt", { sessionID: id })`. An idle (`session.idle`, or `session.status` `idle`) of a session in `inTurn` removes it; a new `"child"` kind removes it too; when the set becomes empty, `ws("stop", { sessionID: <that id> })`. A `retry` status, a repeated `busy` and an idle of a session not in the set send nothing.
- D5. Main. For a candidate id with `kind == "top"` and a defined `act`: when `main` is null or `act > mainAct`, `main = id` and `mainAct = act`, and when `id !== sent`, `sent = id` and `ws("session", { sessionID: id })`. An `info` event never activates, so a late `info` of an older session (`session.updated`, `session.deleted` or any other type) cannot take the main session.
- D6. Known limits (spec AU27, written by step 7): (1) a session activated with no `info` event in this process (a TUI switch to an existing session with no `session.updated`) is never sent; its turn signals still work; E2 records whether `session.updated` fires on a TUI switch; (2) `session.deleted` is not handled (no fixture); (3) a turn with no idle event stays busy until agent exit, drain timeout or `down --now`; (4) a child whose `busy` comes before its `info` is in the turn set until its `info` or its idle; while its parent's turn is open this changes nothing, but when the parent's idle comes first (orders X1 and X3 of the plan review, round 1), the set stays non-empty, so the member stays busy until that child's idle (which then sends `stop` with the child's id) or until its `info`, agent exit, drain timeout or `down --now`; both are the safe side; (5) `opencode run` can exit before its queued `stop` runs; the turn ends at agent exit.
- D7. Tests. The stub of `ws_node` also appends one line per `workspace` call to `ws.log`: the event, a space, the stdin JSON. `ws_seq` reads it into `session{}` (no `sessionID`) or `<event> <sessionID>`, and checks that each payload's `cwd` is `/r`. Session ids in the order tests are the plain strings `A`, `B`, `K`, `K1`, `K2`, `P`, `X`, `Y`. Chain drain (plan review round 1, B1): the driver calls `process.exit(0)` after its last awaited hook, so a queued call that has not run is lost. Every order test therefore runs with `tool: true` (the default of `ws_opts`) and `main` = `A`: `tool.execute.before` on `task` queues `pre-tool` last and waits for it, and the chain runs calls one after another, so the driver exits only after every earlier call ran. Each member order list therefore ends with `pre-tool A`; the non-member run (P14) has no `workspace` call at all. No driver option and no new wait are added.

  const act = new Map();
  let n = 0;
  let main = null;
  let mainAct = 0;
  let sent = null;
  const inTurn = new Set();
  const isId = (s) => typeof s === "string" && s !== "";
  const leave = (id) => {
    if (inTurn.delete(id) && inTurn.size === 0) ws("stop", { sessionID: id });
  };
  const consider = (id) => {
    const a = act.get(id);
    if (kind.get(id) !== "top" || a === undefined || (main !== null && a <= mainAct)) return;
    main = id;
    mainAct = a;
    if (id !== sent) {
      sent = id;
      ws("session", { sessionID: id });
    }
  };
  const step = (e) => {
    const id = sessionOf(e);
    const p = e.properties || {};
    const info = p.info && typeof p.info === "object" ? p.info : null;
    const infoId = String(e.type).startsWith("session.") && info && isId(info.id) ? info.id : null;
    if (infoId !== null && !kind.has(infoId)) {
      kind.set(infoId, info.parentID ? "child" : "top");
      if (info.parentID) leave(infoId);
    }
    const busy = e.type === "session.status" && statusOf(e) === "busy";
    const idle = e.type === "session.idle" || (e.type === "session.status" && statusOf(e) === "idle");
