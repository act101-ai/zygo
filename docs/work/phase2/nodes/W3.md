# W3 — Multiplexer trait, tmux implementation, tmux test gate

**Spec:** `docs/specs/2026-11-20-workspaces-design.md` W§13, W-C3, W-C8; AU7, AU54, AU55, AU62, AU68, AU87 (1), AU96, AU99; W§19 (private server, list-panes format). Trait operations: version, socket_path, session_exists -> SessionAnswer, new_session (first pane, start dir, size, env, argv; returns the first window index), resize_window (window, width, height), unset_window_option (window, name), set_env, hide_env (-r), set_session_option, set_hook, new_window, split_window, select_layout, select_window, select_pane, zoom, list_panes, show_pane_option, set_pane_option, display, kill_session, attach, switch_client. `set_hook` with window scope for `window-unlinked`: on tmux 3.2 tmux stores it on the window, on 3.3 and later on the session (PW6 6.30). Tests that list hooks read `show-hooks` of the session and of each window. AU96 as amended 2026-11-22 (first-window `resize-window`, `window-size` unset; PW6 6.11). Test gate: tmux tests use W3's `mux::testing::require_tmux`: they run when tmux 3.2 or later is on `PATH`, skip with a printed reason otherwise, and are `cfg(unix)` (operator, 2026-11-21). `mux::testing` is `pub` behind `#[cfg(feature = "test-hooks")]`; the crate's own tests reach it through W1's self dev-dependency, and `crates/zygo` reaches it through M1's feature line. No test changes the process environment: `Tmux::new` takes the tmux program, and `require_tmux()` calls `require_tmux_at` with the `tmux` it finds by walking `PATH` (std only). The 3.1 case passes a stub script to `require_tmux_at` (`cfg(unix)`)
