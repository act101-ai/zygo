### Control protocol (the one definition; steps below refer to it)

**Control mode.** The stub is in control mode when `ZYGO_STUB_CONTROL` is set; its value is the control directory. Without it the stub behaves as today (all existing tests stay unchanged), plus `session-arg.json`. One control directory serves one stub process at a time.

**Files in the control directory.**

- `steps`: UTF-8, one step per line, each line ends with `\n`. `stub_control(dir, step)` does `create_dir_all(dir)`, opens `dir/steps` with `OpenOptions::new().create(true).append(true)` and makes one `write_all(format!("{step}\n").as_bytes())`. It checks nothing else.
- `done`: written only by the stub, append mode, one line per event: `start <pid>` when the stub enters the control loop, and the exact text of each step after that step has finished (for `exit`, before the process exits).

**Loop.** After all capture files of today are written: call the `SessionStart` hooks, append `start <pid>` (`std::process::id()`), then loop: read `steps` (missing file = empty); take only lines that end with `\n`; the cursor starts at the number of lines in `done` that do not start with `start ` (so a new stub process on the same directory does not run a finished step again; a step that did not finish runs again); run line number `cursor`, append it to `done`, add 1; when there is no new line, sleep 20 ms and read again. The loop ends only by an `exit` step, a failed step, or a signal. The stub installs no signal handler: a signal ends it by the default action. In control mode `ZYGO_STUB_EXIT` is not read and the `shell.json` block (`stub.rs:123-130`) does not run.

**Steps.**

| Step line | Action |
|---|---|
| `hook <Event>` or `hook <Event> <JSON object>` | `<Event>` is one of `UserPromptSubmit`, `PreToolUse`, `Stop`, `StopFailure`, `SubagentStart`, `SubagentStop`. Build the input (below), replace each top-level key that the JSON object names, call the hooks of the event. |
| `request <ms>` | One model request (below); `<ms>` is a `u64`. |
| `exit <code>` | Append the line to `done`, then `std::process::exit(code)`; `<code>` is an `i32`. |
| any other line, a failed parse, a failed request | `eprintln!("stub-agent: bad step: {line}: {reason}")`, exit code 2, no line in `done`. |

**Session id.** The first of `--session-id`, `--resume`, `-s` in argv that has a next argument gives `(flag, id)`. The stub writes `$ZYGO_STUB_OUT/session-arg.json` = `{"flag":<flag>,"id":<id>}` (in both modes; no file when argv has none). The hook `session_id` is that id, else `format!("00000000-0000-4000-8000-{:012x}", std::process::id())`.

**Hook input.** Common keys: `session_id`; `transcript_path` = `$ZYGO_STUB_OUT` joined with `transcript.jsonl` (the file is not made); `cwd` = the stub's current directory; `hook_event_name`. Added keys (shapes of `fixtures/claude-code/hooks/*.json`):

| Event | Added keys |
|---|---|
| `SessionStart` | `"source"`: `"resume"` when the flag is `--resume`, else `"startup"` |
| `UserPromptSubmit` | `"prompt":"stub prompt"` |
| `PreToolUse` | `"tool_name":"Agent"`, `"tool_input":{"description":"stub","prompt":"stub","subagent_type":"claude","run_in_background":false}`, `"tool_use_id":"toolu_stub"` |
| `Stop` | `"stop_hook_active":false`, `"background_tasks":[]` |
| `StopFailure` | none (no pinned fixture) |
| `SubagentStart` | `"agent_id":"stub-sub-1"`, `"agent_type":"claude"` |
| `SubagentStop` | `"agent_id":"stub-sub-1"`, `"agent_type":"claude"`, `"stop_hook_active":false`, `"background_tasks":[]` |

**Hook call.** Settings are the parsed `--settings` file (`stub.rs:96-107`; none = no hook runs). For each entry of `settings.hooks.<Event>` in order, and each `command` string of its `hooks` in order: for `PreToolUse` only, skip an entry whose `matcher` is a string that is not `*` and has no `|`-separated part equal to the input's `tool_name`. Run `<shell> -c <command>` with the input as compact JSON on stdin (ignore a stdin write error; close stdin), stdout captured; `<shell>` is `$ZYGO_STUB_SHELL` when set, else `/bin/sh`. Append one line to `$ZYGO_STUB_OUT/hooks.jsonl`: `{"event":<Event>,"command":<command>,"input":<input>,"out":<stdout, trimmed>,"code":<exit code, -1 when none>}` (`out` and `code` as `result`, `stub.rs:47-52`).

**Model request.** `ZYGO_URL` must start with `http://`; the text up to the next `/` is the authority; the rest, without a trailing `/`, is the prefix. Token = trimmed text of `$ZYGO_SESSION_DIR/token`. With `std::net::TcpStream` send exactly these header lines (each ends with `\r\n`, then an empty line, then the body): `POST <prefix>/anthropic/v1/messages HTTP/1.1`, `host: <authority>`, `content-type: application/json`, `anthropic-version: 2023-06-01`, `x-zygo-session: <$ZYGO_SESSION>`, `x-api-key: <token>`, `content-length: <n>`, `connection: close`. Body: `{"model":<$ANTHROPIC_MODEL, else "lead">,"max_tokens":1,"stream":true,"messages":[{"role":"user","content":"stub hold <ms>"}]}`. Read the reply to end of stream with no timeout; status = the second space-separated word of the first line as `u16`. Append `{"hold_ms":<ms>,"status":<status>}` to `$ZYGO_STUB_OUT/requests.jsonl`. Any status is a finished step; a missing variable, a URL that is not `http://`, a connect error or an unreadable status is a failed step. The request stays open until the server ends the reply: the test server (or a test provider behind the real proxy) holds it, and reads the time from the `stub hold <ms>` text.

  fn wait_done(ctl: &Path, n: usize) -> Vec<String> {

          assert!(Instant::now() < end, "done has {l:?}, want {n} lines");

      }

          assert!(Instant::now() < end, "the stub did not exit");
          std::thread::sleep(Duration::from_millis(10));
      }

### Task 5: model request through the proxy, held open

- [ ] **5.1 Write the test.** Append to `stub_member.rs`. The listener plays the proxy: it sends the request it read to the test, then holds the reply until the test releases it.

  ```rust
  #[test]
  fn model_request_goes_to_the_proxy_and_stays_open() {
      use std::io::{Read, Write};
      use std::sync::mpsc::channel;
      let l = std::net::TcpListener::bind("127.0.0.1:0").unwrap();
      let url = format!("http://{}/", l.local_addr().unwrap()); // `ZYGO_URL` ends with `/`, as `Url::to_string` gives it
      let (req_tx, req_rx) = channel::<String>();
      let (go_tx, go_rx) = channel::<()>();
      let server = std::thread::spawn(move || {
          let (mut c, _) = l.accept().unwrap();
          let (mut buf, mut b) = (Vec::new(), [0u8; 4096]);
          let text = loop { // headers, then `content-length` body bytes
              let n = c.read(&mut b).unwrap();
              assert!(n > 0, "the stub closed the request early");
              buf.extend_from_slice(&b[..n]);
              let t = String::from_utf8_lossy(&buf).into_owned();
              if let Some((head, body)) = t.split_once("\r\n\r\n") {
                  let len: usize = head.lines().find_map(|h| h.strip_prefix("content-length: ")).unwrap().parse().unwrap();
                  if body.len() >= len { break t; }
              }
          };
          req_tx.send(text).unwrap();
          go_rx.recv().unwrap(); // hold the reply open
          c.write_all(b"HTTP/1.1 200 OK\r\ncontent-type: text/event-stream\r\nconnection: close\r\n\r\ndata: {}\n\n").unwrap();
      });
      let s = spawn_in(tempfile::tempdir().unwrap(), &[], true, &url);
      harness::stub_control(&s.ctl, "request 20000").unwrap();
      let req = req_rx.recv_timeout(BOUND).unwrap();
      let (head, body) = req.split_once("\r\n\r\n").unwrap();
      let lines: Vec<&str> = head.split("\r\n").collect();
      assert_eq!(lines[0], "POST /anthropic/v1/messages HTTP/1.1");
      for h in ["content-type: application/json", "anthropic-version: 2023-06-01", "x-zygo-session: s-1", "x-api-key: tok-1", "connection: close"] {
          assert!(lines.contains(&h), "{h} not in {lines:?}");
      }
      assert_eq!(serde_json::from_str::<Value>(body).unwrap(),
          json!({"model": "lead", "max_tokens": 1, "stream": true, "messages": [{"role": "user", "content": "stub hold 20000"}]}));
      // the request is open: the server has not replied, so the step is not finished
      assert_eq!(wait_done(&s.ctl, 1).len(), 1);
      assert!(jsonl(&s.out.join("requests.jsonl")).is_empty());
      go_tx.send(()).unwrap();
      assert_eq!(wait_done(&s.ctl, 2)[1], "request 20000");
      assert_eq!(jsonl(&s.out.join("requests.jsonl")), [json!({"hold_ms": 20000, "status": 200})]);
      server.join().unwrap();
  }
  ```
