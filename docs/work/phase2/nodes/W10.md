AU18 sandbox guard: before the detach, `down` compares `DownOpts.mnt_ns("self")` with `DownOpts.mnt_ns(<#{pid} of tmux_socket>)`; when the second is unreadable or different, `down` does not detach and exits 1 with the AU18 text. AU26 interrupted turn, PW7 7.2 fallback (author's call, 2026-11-22): a turn ended with Esc sends no `Stop` or `StopFailure`, so `busy` stays `true`. In the drain loop (W§9.3 step 5), `down` keeps for each member the time of the first poll in an unbroken run of polls where `drain::idle` returned `Idle::TurnOpen { rule_skipped: false }`; any other result clears it. Only `TurnOpen { rule_skipped: false }` polls count toward `INTERRUPTED_TURN_AFTER`; a member whose polls give `TurnOpen { rule_skipped: true }` waits until the drain timeout (AU26). When that run reaches 60 s, the member counts as idle and `down` prints `zygo: <member>: no Stop since its last prompt (interrupted turn); treated as idle` once for that member in that `down` (with `--all`, once per member of each workspace). When `drain::idle` returns `IdleRuleSkipped` or `TurnOpen { rule_skipped: true }`, `down` prints the AU26 rule-skipped line `zygo: <member>: proxy request state not usable; idle rule 3 skipped` once for that member in that `down`. `down` also prints the AU26 skip line for `Busy { rule_skipped: true }` (W9 round 2: `drain::Idle::Busy` is `Busy { reason: String, rule_skipped: bool }`). `down` passes `drain::idle` the results of `activity::read` and of the proxy status call, each error as its text (`format!("{e:#}")`), and in the timeout report prints the `Busy` reason of each busy member, or `no Stop since its last prompt` for a member at `TurnOpen` (W§9.3 step 6). The 60 s is the constant `down::INTERRUPTED_TURN_AFTER`; it does not change the `--timeout` rule: a timeout that passes first exits 1 as for a busy member. `display-message -p -t =<missing>:` exits 0 with an empty line (W3 probe, tmux 3.7c), so read `@zygo-ws` only after `session_exists`
