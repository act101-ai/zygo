Step 4 calls `snapshot::run(paths, mux, id, None, true, snapshot::OP_WAIT)`. `SnapshotOutcome::Pending` means the final snapshot is queued in `snapshot.pending` with `force` and runs after the next write: `down` calls `snapshot::after_write(paths, mux, id, snapshot::OP_WAIT)` itself after each of its own writes under `lock` from step 4 on (step 6 `phase = up`, step 7 `phase = stopping`, step 8). ### Decisions

Each decision is the author's call (2026-11-22). Where the spec gives two readings, the decision takes the side that never loses work, busy over idle. R1-R12 above are folded in.

- D1. Output. Only `zygo: <name> is down (<n> agents saved)`, `zygo: <name> is not running`, `zygo: no workspace is up` and `zygo: down started; end your turn` go to `out`; every other line goes to `err` (W7 D2). `run` and `down` never call `process::exit`.
- D2. Member label. `<member>` in the AU26 texts and in every member line is `<name> pane <key>` (for example `app pane kaaaaaaaa`). Names (AU84 `^[a-z0-9-]{1,32}$`) and keys (`^k[a-z2-7]{8}$`) are validated at each read, so the label needs no escape. Text from outside zygo (a subagent id or type, a pane command, a work unit, a marker id) is printed through `zygo_core::esc`.
- D3. Texts that the spec does not fix (each one line; exit code where the line ends `down`):
  - no tmux, an old tmux, an unreadable version: the three texts of W7 D3 (`zygo: workspaces need tmux; install tmux 3.2 or later`, `zygo: tmux <major>.<minor> is too old; workspaces need tmux 3.2 or later`, `zygo: cannot read the tmux version: <error>`), exit 2
  - `DownTarget::Session(None)`: `zygo: this session is not in a workspace`, exit 1; `Session(Some(id))` with an id that is not valid: `zygo: invalid workspace id <esc(id)>`, exit 1; a valid id with no state: `zygo: no workspace with id <id>`, exit 1
  - `op.lock` held: `zygo: up or down is in progress for <name>` (the W§8.1 step 4 text), exit 1; with `--all` the same line and a skip
  - `--all`, a state that cannot be read: `zygo: skipped workspace <id>: <StateError text>`; no readable state with a phase other than `down`: `zygo: no workspace is up`
  - a tmux error: `zygo: tmux: <error>`, exit 1; a `workspace.json` lock not taken within 5 s: `zygo: workspace <name> is busy; try again`, exit 1
