**Facts of the live code (read before you start):**

- `SessionStatus` is in `client.rs:39-82`. It derives `Default`. Each HUD field has `#[serde(default, skip_serializing_if = "Option::is_none")]`. Every literal outside `SessionState::status` (`session.rs:330-351`) uses `..Default::default()` or `..<value>`, so only `status` gets new lines.
- "Accepted on the forward path" (AU91) is the line `app.sessions.accept(s)?;` in `forward::run` (`forward.rs:373`; the spec cites it as `:339`, its number before the HUD). A request refused before that line is not counted and does not set `last_request_end`.
- `Pending` (`forward.rs:208-264`) is the value that lives until the request ends. `handle` (`forward.rs:275`) holds it in `slot` for a reply with no stream. `run` moves it into `Flow` (`forward.rs:1036`), which is the state of the response body stream. Thus `Pending` drops at the normal body end, at an upstream error, and when the client drops the body. The decrement goes there.
- `Pending::drop` ends with `self.sink.send(..)`. `ProxyHandle::usage_written(n, limit)` (`server.rs:317`, test hook) returns true when `n` rows were handled, also with no usage database (`tee.rs:375-380`). So the decrement must come before `sink.send`: a test that waits with `usage_written` then reads a count that is final. This is the wait of every test below; no test uses a sleep.
- Time: `Clock::utc()` (`session.rs:46-49`), `fn rfc3339(t: OffsetDateTime) -> String` (`session.rs:249`). `App.clock` is `Arc<dyn Clock>` (`server.rs:253`). Tests use `ManualClock` (`advance`, `utc`).
- The status route (`routes.rs:231-235`) returns `Json(s.status())`. Local mode and `zygo serve` use the same `routes::router` (`server.rs:59`, `serve.rs:167`). In `session_api.rs` a serve-mode session is a team session: `team_session(&raw, &url, "Bearer <token>")` (`session_api.rs:193`).
- Helpers of `session_api.rs` to reuse: `ctx`, `TestTeam`, `req`, `client`, `http_client`, `Raw::call`, `sess`, `sp`, `team_session`, `sse` (`:1076`), `routed_upstream` (`:1222`, the model for a fake upstream), `start_routed` (`:1256`, the model for the config text), `post_model` (`:1276`), `status_after` (`:1282`: waits for `n` rows, then reads the status).

#[test]
fn au91_count_is_1_while_streamed_and_0_after_end() { // AU91, W§19: normal end of a streamed body
    let d = TempDir::new().unwrap();
    let (mut up, h, c, _) = start_held(&d);
    let raw = Raw::new();
    let g = h.create_session(req()).unwrap();
    let k = client(&h, &g, &d);
    let s = k.status().unwrap();
    assert_eq!((s.requests_in_flight, s.last_request_end), (Some(0), None));
    let (_, v, _) = raw.call(&h.url(), "GET", &sp(&g), &sess(&g), None);
    assert_eq!(v["requests_in_flight"], json!(0));
    assert!(v.get("last_request_end").is_none(), "{v}");
    // Refused before `accept`: not a request of AU91.
    assert_eq!(post_model(&raw, &h, &g, json!(5)), 400);
    let s = status_after(&h, &k, 1);
    assert_eq!((s.requests_in_flight, s.last_request_end), (Some(0), None));
    up.send(Ok(first_chunk()));
    let open = open_stream(&h, &g);
    let s = k.status().unwrap();
    assert_eq!((s.requests_in_flight, s.last_request_end), (Some(1), None));
    c.advance(Duration::from_secs(90));
    up.send(Ok(last_chunk()));
    up.end();
    assert!(open.rest().is_ok());
    let s = status_after(&h, &k, 2);
    assert_eq!(s.requests_in_flight, Some(0));
    assert_eq!(end_time(&s), c.utc()); // RFC 3339; the clock stood still after the end
}

#[test]
fn au91_client_drop_returns_count_to_0() { // Review focus 3; AU91, W§19
    let d = TempDir::new().unwrap();
    let (up, h, c, _) = start_held(&d);
    let g = h.create_session(req()).unwrap();
    let k = client(&h, &g, &d);
    up.send(Ok(first_chunk()));
    let open = open_stream(&h, &g);
    assert_eq!(k.status().unwrap().requests_in_flight, Some(1));
    drop(open); // the client closes; the upstream body stays open (`up` lives to the end of the test)
    let s = status_after(&h, &k, 1);
    assert_eq!(s.requests_in_flight, Some(0));
    assert_eq!(end_time(&s), c.utc());
    drop(up);
}

#[test]
fn au91_upstream_error_returns_count_to_0() { // AU91, W§19: the upstream body fails
    let d = TempDir::new().unwrap();
    let (up, h, c, _) = start_held(&d);
    let g = h.create_session(req()).unwrap();
    let k = client(&h, &g, &d);
    up.send(Ok(first_chunk()));
    let open = open_stream(&h, &g);
    assert_eq!(k.status().unwrap().requests_in_flight, Some(1));
    up.send(Err(std::io::Error::other("cut")));
    let _ = open.rest(); // the body ends or fails; the proof is the wait below
    let s = status_after(&h, &k, 1);
    assert_eq!(s.requests_in_flight, Some(0));
    assert_eq!(end_time(&s), c.utc());
}

#[test]

    let d = TempDir::new().unwrap();
