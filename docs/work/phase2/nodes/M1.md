### Design calls (the contract and the spec leave these open)

- D1. AU69 (controller decisions 2026-11-23, Spec field). (b) is dropped: the sweep deletes no `results/<pane key>/` folder (test `w18_61_the_sweep_deletes_no_workspace_result`). (a): a session folder whose `results` is a symlink whose canonical target is under the canonical workspace cache is removed only when (1) it is not `live`, (2) its newest change (`changed`, the base measure) is 24 h (`KEEP`) or more before `now`, and (3) `live()` is still false when checked again right before the removal. Then the link is removed first (`remove_file`), and only when that worked the folder (`remove_dir_all`, which does not follow links). The link target is never touched. A target that cannot be canonicalized (missing, or the cache missing) keeps the folder. Step 37 writes this into AU69, W§18 #30 and #61, and the W§16 row. W8 D16 ("AU69 (b) sweeps only the caches of workspaces that `list_all` still lists") gives a reason that referred to the removed (b); it is history only and changes nothing in W8's code (`nodes/W8.md` is not in Files).
- D2. Every `tmux` of the workspace verbs (`up`, `down`, `attach`, `ws snapshot`, `ws forget`, `ws forget-pane`, `ls`, and the slash `down` and `ls`) is `tmux_program()`: the first `tmux` in the absolute entries of `PATH` (the rule of the doctor probes, `doctor.rs:130-135`).
