### Interface of `scripts/premises/live-mail.sh`

- `sh scripts/premises/live-mail.sh --pm` runs PM1, PM2, PM3 and prints `LIVE PM1 …`, `LIVE PM2 …`, `LIVE PM3 …` (each `verified` or `failed`), exit 0. Fixtures: `fixtures/claude-code/mail/pm1.txt`, `pm2.txt`, `pm3.txt`, `fixtures/opencode/mail/pm2.txt`, `pm3.txt`.
- `sh scripts/premises/live-mail.sh --m12` runs the first half of M§13 #12 (the second half, a resumed member's session text, is not in ML-19) and prints one `LIVE M12 …` line, exit 0. Fixture: `fixtures/claude-code/mail/m12.txt`.
- Any other argument list: `usage: live-mail.sh --pm | --m12`, exit 2, checked before `lib.sh` is sourced (so no scratch dir and no agent lookup).
- Exit 1 with one `live: …` line when a precondition fails: tmux missing or below 3.2 (`ver_ge`, as `live-detach.sh:54-55`), `jq`, `python3` or `perl` missing, `pinned_agents`, a path with a quote or a space, socket path over 100 characters; `--m12` also: `$ZYGO_BIN` not executable.
- Every tmux call is `"$TMUX_BIN" -S "$SOCK" -f /dev/null …` with `SOCK="$ZP_PRIV/s"`, `ZP_PRIV=$(mktemp -d "${TMPDIR:-/tmp}/zm.XXXXXX")`, apart from the one `"$TMUX_BIN" -V`. No `lib.sh` tmux helper (`tmux_own`, `tmux_claude`, `tmux_send`) is used, so `live_end` never calls the default server.
- Trap `zm_end` (copy of `zp_end`): kill the private server, the `LIVE_PIDS`, remove `$ZP_PRIV`, then `live_end`. With `--m12` it first runs `rclean` when a workspace was started.
- Fixtures are written to `$BASE/fx-claude-code` and `$BASE/fx-opencode` and copied file by file (no `rm -rf`, the two modes share the folders) into `$REPO_DIR/fixtures/claude-code/mail/` and `$REPO_DIR/fixtures/opencode/mail/` at the end of the run, a `failed` run included (ML-17: a `failed` line still passes).
- `PW_TEST=1 PW_TICKS=<n>` (from `pw_ticks`) shortens every wait; only the self-test sets it.
