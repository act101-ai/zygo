### Decisions (author)

1. One function, `never_worse`, holds O§8.3 items 2-6. Item 1 is `run`: it `unwrap`s `trim_in_with`, so an `Err` (in the hook process, exit code not 0 under C6) or a panic fails the test (O§8.4: in process, through `trim_in`).
2. `problems` starts with `never_worse(c, g)`, so `settle` (bless) refuses a view that fails an O§8.3 check (O§8.1 "Bless refuses … or that fails any other O§8.2-8.3 check"). The four O§8.3 checks already in `problems` move into `never_worse` with their message text unchanged except the cite, so the OS-35 tests that match `empty must_keep line`, `does not name the stored id` and `must_keep line not in the view` still pass. `stored_bytes`, `view_bytes`, `result_id` (O§7.8, O§7.9) and the floors stay in `problems`.
3. Each check and its spec line:
   - Item 2 (O§8.3 item 2, O-C4, O§7.8 use rule): when `g.out` is not empty, there is a row and a stored result, and `row.0 >= row.1 && row.0 - row.1 >= MIN_SAVING_BYTES as u64`. Empty `g.out` is "no change" and passes.
   - Item 3 (O§8.3 item 3): when `g.out` is not empty, `g.view` contains `ZERO_ID` and the `Store::get` data equals `raw_text(c)`.
   - Item 4 (O§8.3 item 4, O-C9): an empty `must_keep` line makes the case invalid (always); when `g.out` is not empty, each `must_keep` line `holds` in the view lines plus the `stderr_out` lines, with `log` = row shaper is `log`.
   - Item 5 (O§8.3 item 5, O§7.6 hidden forms and go test rules, O-C9): when the row's shaper is `libtest`, `pytest` or `gotest` and `g.view` starts with `[zygo shaped this output: ` (so the runner is the last step and no size view ran, O§7.8, O§7.9). `t` = the text step 3 saw: `src` cleaned with `clean(src, reuse(c))` (`None` keeps `src`), then, when `!reuse(c)`, `dedup(&t)` (`None` keeps `t`). `body` = `g.view` after its first `\n`. Each line `hidden_lines(&t, body)` gives must satisfy `hidden_by(r, line)`, or, for `Runner::Gotest` only, its number is in `gotest_passed_lines(&t)` ("belongs to a passed go test by the go test rules" is a rule of the go test row). `hidden_lines` = `None` is a problem: the check cannot follow the view line by line against the text.
   - Item 6 (O§8.3 item 6, O§7.3, O-C1): when `raw_text(c).len() > SHAPE_MAX_BYTES`, `g.view == size_view(&src, &Stored { id: ZERO_ID, tool: "Bash", bytes: raw.len(), lines: raw.lines().count(), kind: Kind::Text, created_at: 0, session: None, data: vec![] }, &results_cfg())`.
