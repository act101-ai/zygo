# DR-10 — Agent transitions: the D§6.6 rule for one record change

**Spec:** `docs/specs/2026-11-24-decision-records-design.md` D§6.6 (the agent rows; `fixed` and `superseded` final), D§6.3 ("frozen" keys: `kind`, `class`, `unit`, `round`, `role`, `id`; operator keys), D§9.4 step 9 (what a change must be), D-C4, D-C5
**Files:** `crates/zygo-work/src/lib.rs`, `crates/zygo-work/src/gate/mod.rs`, `crates/zygo-work/src/gate/transition.rs`, `crates/zygo-work/tests/decision_transition.rs`
**Consumes:** `Record` (DR-1), `Status` (DR-1), `NameKind` (DR-1), `name_kind` (DR-1)
**Produces:** `gate::transition::Version` (`Absent | Malformed | Valid(Record)`); `gate::transition::RangeCtx { pub range: BTreeSet<String>, pub superseding: BTreeSet<String> }` (full commit ids of the node range; ids named in `supersedes` by records added in the range); `gate::transition::agent_change(id: &str, old: &Version, new: &Version, ctx: &RangeCtx) -> Option<String>` (`None`: an allowed agent transition; `Some(problem)` otherwise)
**Acceptance:** `cargo test -p zygo-work --locked --test decision_transition` → all pass. One case per D§6.6 agent row allowed (none → `open`; `open` → `open` with non-frozen keys; `open` → `fixed` with `fixed_by` in the range; `open` → `superseded` named by a record added in the range; `overturned` → `fixed`; `ratified` with `promoted_to` gains `promoted_by` in the range) and one problem each for: a change of `kind`, `class`, `unit`, `round` or `role`; an agent writing `ratified` or `overturned`; an agent writing `reviewed`, `review_note`, `promoted_to` or `promotion`; `fixed_by` or `promoted_by` outside the range; `superseded` that no added record names; a change of a `fixed` or `superseded` record; a deleted record (`new = Absent`); a malformed new version; a new record created with a status other than `open` or with an operator key.
