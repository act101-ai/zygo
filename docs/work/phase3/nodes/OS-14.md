# OS-14 — Size view over any text, and the shaped marker

**Spec:** `docs/specs/2026-11-24-output-shaping-design.md` O§7.8 (the shaped marker; `<n>`, `<bytes>` and `<id>` are the raw text's; step 5 is the §10.1 view of the shaped text), O§7.3 step 5
**Files:** `crates/zygo-results/src/view.rs`, `crates/zygo-results/tests/results.rs`
**Consumes:** `Step` (OS-10), `Stored.session` (OS-1)
**Produces:** `view::size_view(text: &str, s: &Stored, cfg: &ResultsConfig) -> String` (head and tail of `text`, with the §10.1 marker of `s`'s lines, bytes and id), `view::shaped_view(steps: &[Step], text: &str, s: &Stored) -> String` (the O§7.8 marker line, then `text`); `view::view(s, cfg)` equals `size_view(&s.text(), s, cfg)`
**Acceptance:** `cargo test -p zygo-results --test results` → all pass: every existing view test is unchanged; `shaped_view(&[color codes removed, repeated lines counted], "x", s)` equals `[zygo shaped this output: color codes removed, repeated lines counted. The full output (<s.lines> lines, <s.bytes> bytes) is saved as result <s.id>; read it with result_view, result_search or result_tree.]` + `\n` + `x`; `size_view` of a text shorter than the raw text keeps the raw text's numbers in its marker and stays within `VIEW_CAP_BYTES`
