## Plan

Notation: `W` is this worktree, `CAP` is `"$W/scripts/fixtures/capture-shaping.sh"` (OS-16; it writes to `$W/fixtures/shaping/<shaper>/<case>/`, scrubs the run dir to `/repo`, `$HOME` to `/home/user`, the user and host names), `S` is a fresh `mktemp -d` scratch dir per case. `.gitattributes` already holds `fixtures/shaping/** -text`, so git keeps the bytes. Every capture must end with `meta.exit` 0.

- [x] 1. Set the shell up once: `export GIT_CONFIG_GLOBAL=/dev/null GIT_CONFIG_NOSYSTEM=1 GIT_AUTHOR_NAME=fixture GIT_AUTHOR_EMAIL=fixture@example.invalid GIT_COMMITTER_NAME=fixture GIT_COMMITTER_EMAIL=fixture@example.invalid; unset CARGO_TARGET_DIR`. This keeps personal git config, identity and a shared target dir out of the runs and changes no git config file. Check: `git config --get user.email` prints nothing; `test -z "${CARGO_TARGET_DIR:-}"`.
- [x] 2. `clean/cargo-test-color`. Set up a scratch crate with 60 passing tests: `cd "$S" && cargo new --lib --vcs none scratch -q && cd scratch && perl -e 'printf "#[test]\nfn passes_%03d() { assert_eq!(%d + 1, %d); }\n", $_, $_, $_ + 1 for 1..60' > src/lib.rs`. Capture: `ZYGO_CAPTURE_TOOL="cargo $(cargo --version | cut -d' ' -f2)" "$CAP" clean cargo-test-color -- cargo test --color always -- --color always`. Write must_keep (the two `test result:` lines, lib and doc-tests, without color codes): `cd "$W/fixtures/shaping/clean/cargo-test-color" && perl -pe 's/\e\[[0-9;]*m//g' stdout | grep '^test result: ok\.' > must_keep`. Check: `perl -0777 -ne 'exit !(/\e/)' stdout && perl -0777 -ne 'exit !(/\e/)' stderr` exits 0, and `wc -l < must_keep` is 2. As built: replaced by review round 1 fix 3 (`must_keep` holds the two `running N tests` lines).
- [x] 3. `clean/git-clone-progress`. Set up a source repo with 2,000 files: `cd "$S" && git init -q -b main src && (cd src && i=1; while [ $i -le 2000 ]; do echo "file $i" > f$i.txt; i=$((i+1)); done; git add . && git commit -qm "2000 files")`. Capture: `ZYGO_CAPTURE_TOOL="git $(git --version | cut -d' ' -f3)" "$CAP" clean git-clone-progress -- git clone --progress --no-local src dst`. `--no-local` is necessary: a plain local-path clone copies objects and prints no progress (probed with git 2.50.1). Write must_keep (the text after the last `\r` of each line): `cd "$W/fixtures/shaping/clean/git-clone-progress" && perl -pe 's/.*\r//' stderr | grep -E "^(Cloning into 'dst'\.\.\.|Receiving objects: 100% .*done\.)$" > must_keep`. Check: `perl -0777 -ne 'exit !(/\r/)' stderr` exits 0; `wc -l < must_keep` is 2.
- [x] 4. `clean/git-diff-color-crlf`. Set up a repo with a 7-line CRLF file and change line 4: `cd "$S" && git init -q -b main d && cd d && printf 'line one\r\nline two\r\nline three\r\nline four\r\nline five\r\nline six\r\nline seven\r\n' > crlf.txt && git add crlf.txt && git commit -qm init && perl -pi -e 's/four/4/' crlf.txt`. Capture: `ZYGO_CAPTURE_TOOL="git $(git --version | cut -d' ' -f3)" "$CAP" clean git-diff-color-crlf -- git diff --color=always`. The six context lines end in `ESC[m\r\n`. Write must_keep: `printf 'diff --git a/crlf.txt b/crlf.txt\n' > "$W/fixtures/shaping/clean/git-diff-color-crlf/must_keep"` (O§8.1: each `diff --git` line, written without color codes as in the cleaned text). Check: `perl -0777 -ne 'exit !(/\r\n/ && /\e/)' stdout` exits 0; `perl -pe 's/\e\[[0-9;]*m//g' stdout | grep -qx 'diff --git a/crlf.txt b/crlf.txt'`.
- [x] 5. `dedup/build-repeated-warning`. Set up a crate whose build script prints one warning 40 times: `cd "$S" && cargo new --lib --vcs none warnbuild -q && cd warnbuild && printf 'fn main() { for _ in 0..40 { println!("cargo:warning=libfoo not found; using the bundled copy"); } }\n' > build.rs`. Capture: `ZYGO_CAPTURE_TOOL="cargo $(cargo --version | cut -d' ' -f2)" "$CAP" dedup build-repeated-warning -- cargo build`. cargo does not collapse build-script warnings (probed with cargo 1.98.0: 30 equal lines out of 30). Write must_keep (the `Compiling` and `Finished` lines; they stay whole after dedup): `cd "$W/fixtures/shaping/dedup/build-repeated-warning" && grep -E '^ +(Compiling|Finished) ' stderr > must_keep`. Check: `perl -ne '$n = $_ eq $p ? $n + 1 : 1; $p = $_; $m = $n if $n > $m; END { exit !($m >= 40) }' stderr` exits 0 (one run of 40 equal lines, so the O§8.2 50 % dedup floor is reachable); `wc -l < must_keep` is 2.
- [x] 6. `dedup/already-repeated`. Set up a repo whose log subjects hold a run of 5 equal lines and one line with the suffix: `cd "$S" && git init -q -b main r && cd r && for s in "poll: queue empty [repeated 4 times]" "poll: queue empty" "poll: queue empty" "poll: queue empty" "poll: queue empty" "poll: queue empty" "poll: start"; do git commit -q --allow-empty -m "$s"; done`. Capture: `ZYGO_CAPTURE_TOOL="git $(git --version | cut -d' ' -f3)" "$CAP" dedup already-repeated -- git log --format=%s`. Write must_keep: `cd "$W/fixtures/shaping/dedup/already-repeated" && grep ' \[repeated 4 times\]$' stdout > must_keep`. Check: `perl -0777 -ne 'exit !(/ \[repeated 4 times\]$/m)' stdout` exits 0, and the stdout also has the 5-line run of `poll: queue empty` (without the suffix rule, dedup would change this text, so the case proves O§7.5 "no change").
- [x] 7. Set `meta.source` of each case to name the scratch setup, so a reader can repeat the run: for each folder, `SRC='<setup of step N>, run by capture-shaping.sh in /repo' perl -MJSON::PP -0777 -i -pe '$j = JSON::PP->new->canonical->pretty; $m = $j->decode($_); $m->{source} = $ENV{SRC}; $_ = $j->encode($m)' meta.json`, with the setups "scratch crate, 60 passing tests" (2), "scratch repo of 2,000 one-line files, cloned with --no-local" (3), "scratch repo, 7-line CRLF file, line 4 changed" (4), "scratch crate whose build.rs prints one cargo:warning 40 times" (5), "scratch repo of 7 empty commits" (6).
