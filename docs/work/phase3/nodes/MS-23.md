Reason: OpenCode 1.19.6 makes its session at the first prompt, and the zygo plugin then sends `session` right before `prompt`; after a warm-up turn a round prompt sends only `prompt`. - The hook process lives 10 to 30 ms, which the watcher does not always sample. The child is attributed to the prompt hook by time: it starts before the busy-true sample, which the prompt hook writes after it starts the child (`crates/zygo-hooks/src/workspace.rs`, `start_sync` before the event). "The hook ended before the child" is shown by the child's parent: it is first sampled with the user's systemd as parent (a re-parented process), while the prompt hook of the same workspace was sampled and then ended.
- The sync branch of the evidence run is `zygo/sp1`, not `zygo/mail`: a defect of an earlier attempt of the script (fixed before the evidence run; prompt text sent to a wrong tmux target) started sync children in the HTTPS workspace, which pushed `zygo/mail` (now the default branch of that repository, which GitHub does not let delete) and `zygo/mail2` (deleted). Sub-check 1.4 requires the run's branch and names every branch.
- The two repositories are archived, not deleted: the gh token has no `delete_repo` scope (operator decision: no new scope).
