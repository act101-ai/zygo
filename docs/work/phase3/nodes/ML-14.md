### Rules the code follows

- Unread counts come only from `mail::store::unread` (names in `new/`; no message file is opened). Counts are for keys of `ws.members` only; a folder in `mail/` with no member record (such as `sync/`) is not counted.
- `forget-pane` checks `mail/` with `symlink_metadata` before the record write, as `pane_cache` does for `<id>` and `<sub>` (Round 2 R4): a link at `mail/` refuses with `zygo: cannot forget pane <key> of <name>: <mail path> is a link; it is not followed` and nothing is written or deleted. `mail/<key>` that is a link is removed as a link by `remove_pane`. Nothing outside `mail/<key>` is deleted.
- The maildir removal runs after the record write and after the caches, is tried also after a cache error, and its error is reported like a cache error (first error wins, exit 1). A `mail/<key>` with no member record and no cache is removed (as an orphan cache is today), so a second run recovers.
