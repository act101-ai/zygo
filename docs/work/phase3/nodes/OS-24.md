- Meaning (O§7.8 "When PO2 fails", `docs/specs/2026-11-24-output-shaping-design.md:301`): **verified** = tracer `yes`, err-line `no`. **failed** = tracer `yes`, err-line `yes` (Claude Code shows the original stderr although the hook set it to `""`). Tracer `no` means the hook output was not applied at all; that run does not decide PO2 (Part C2). PO2 also needs the hook input's `tool_response.stderr` to hold `err-line`; else clearing `stderr` proves nothing (Part C2).
- `RUN` = `$N2_SCRATCH/live-<pid>/po2` (`live.sh:103`, `lib.sh:49-67`). With `N2_SCRATCH` set by the caller the run folder is kept (`lib.sh:2-5`, `:33-43`). So Part A sets `N2_SCRATCH`.
