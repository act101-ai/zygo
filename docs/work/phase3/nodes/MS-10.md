Shared rules for every function. Each git call is `git::run` or `git::stream` (S-C4: the builder, the overrides, the deadline). A `RunError` from the runner gives `Git(e, step)`. A non-zero exit gives `Git(RunError::Failed, step)`. `step` is the git subcommand, for example `"fetch"`, `"worktree add"` or `"commit-tree"`. Git output that should be an object id but is not one gives `Git(Failed, step)`. A local file error, or a path that is not UTF-8, gives `Io(<text>)`. An object-id argument that is not `^([0-9a-f]{40}|[0-9a-f]{64})$` gives `Refused("object id")` before any spawn. No function runs `worktree prune`, `merge`, `rebase` or `checkout` (S§6.3, S§12).
