# FX-11 — zygo doctor icon line shows the ✉ mail glyph

**Spec:** — (found in the ML-15 plan and review, F5). `render::glyphs` (`crates/zygo-hooks/src/statusline/render.rs:249`) returns the shared table built by `table` (render.rs:220, 19 entries; `NERD_TABLE` and `PLAIN_TABLE` at render.rs:244-245). `Glyphs.mail` (render.rs:175) is kept out of that table on purpose (comment at render.rs:174). So the `zygo doctor` icon line (`icon_line`, `crates/zygo/src/cmd/doctor.rs:245-250`), documented as "every Nerd glyph of H§6.5", leaves out `✉`. A user whose font has no `✉` cannot find that with `zygo doctor`. Input: `Glyphs.mail` (added by ML-15; Nerd `"\u{2709}"` at render.rs:199, plain `"mail"` at render.rs:217) and `pub fn glyphs(set: IconSet) -> &'static [(&'static str, &'static str)]` (render.rs:249). `icon_line` (doctor.rs:250) collects every entry of `glyphs(IconSet::Nerd)` and holds no count, so doctor.rs needs no change (it is not in Files, which keeps FX-11 free of WD-17 and MS-18). Depends on RT-3 because both change render.rs and statusline_render.rs.
