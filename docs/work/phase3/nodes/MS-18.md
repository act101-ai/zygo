### Drift and decisions (cited)

- P1 (S§7.2 rewritten; change log 2026-11-26). The spec refused a remote address in `read`, `ls <name>` and `watch <name>` with no line and no rule for sync off or reserved forms. One line covers every value with `@` that does not resolve to a local name: `zygo: <value> is not a local address; zygo mail read, ls and watch take a member of this machine`. The local host is the one `send` uses (host in force with sync on; none with sync off or a config that does not load).
- P2 (S§8.1 row 3 rewritten). MS-17's interface note: a `Mode::Cli` sync that does not print its report uses up the S§6.6 note. The `watch` stdout is the message stream of a bounded tool, and a CLI sync also waits 30 s for the lock (`LOCK_WAIT`, `sync.rs:33`). The watch starts the hidden sync child (`zygo mail sync --ws-id <id> --background`, the `ChildSpawner` of `sync_env`, through `env.spawner`): silent, no lock wait, a stop or a panic is one `errors.log` line, the CI note is not used up. It starts one before a look, start to start, and does not wait for it, so no sync delays a look or the `--timeout` (M§13 #7); the child's import shows at a later look (review round 1, F1/F3, lead's decision). It does not call `spawn::trigger` with a gap: that rule reads and writes the hook file `mail/sync/last_start` (S§8.4), so a hook start less than `sync_gap` before the watch would skip the start of the watch, against S§8.1 row 3.
- P3 (S§10.3 rewritten). The sync line had no form. Form: `mail sync: last sync <time>, <n> in the outbox, <m> refused[, last error <check>]`; `<time>` RFC 3339 UTC (the `sent_at` form of M§5) or `never`; a value that cannot be read is `-` (the ML-12 `ls` rule for an unread count, `mail.rs:500`). Off cases: `NoHost` gives the S§7.1 line `zygo: set [mail] host to turn on mail sync; zygo does not publish the system host name`; `BadHost`, `BadBranch`, `BadGap` give `off_line` (MS-17's text); `NotOn` and a config that does not load give no line, so the ML-12 `ls` output and its tests stay as they are for a workspace without sync (the MS-19 `mail_list` and item 8 rule for a config that does not load).
- P4 (S§7.5 rewritten). `zygo doctor` cannot see the tip without a fetch; the condition is `state.json` `last_error` = `Stop::Twin.check_name()`, written by the stopped pass (`sync.rs:222`) and cleared by a pass that ends (`sync.rs:393`). The workspace is that of `workspace_of` (`ZYGO_WORKSPACE`, else the checkout of the current folder); none gives no line.
- P5 (S§10.5 rewritten). `zygo mail read` prints remote values and the body; `read_text` (`mail.rs:531`) already escapes each; W1 checks it.
- P6 (Consumes). The row named `send_remote` (MS-9); this node calls `send_remote_with` (see "Not used"). It also uses `Env` and its traits (MS-2), `AddrError::line` (MS-19) and `Stop` (MS-11).
- P7 (Files). RFC 3339 needs `time` (workspace dependency `Cargo.toml:66`, `formatting` on); `crates/zygo` does not depend on it, so `crates/zygo/Cargo.toml` and `Cargo.lock` change.
- D1. `send_cli` handles a `to` with no `@` as today (M§8, M§10): no config value beyond `cfg.mail`, the same lines, the same exit codes. Only the wake moves to `env.wake` with `env.clock.now()`: in production that is `TmuxWake { tmux: tmux_program() }` at the system time, the body of `wake::after_send` (`crates/zygo-workspace/src/mail/wake.rs:201-207`), so the binary behaves as before; it is called only for a non-empty key list, as `after_send` returns on one. `mail::send` gets `env.clock.now()`.
- D2. A `to` with `@`: `resolve_to(to, own)` with `own` = the host of `sync_for(cfg, &ws.name)` when `Ok`, else empty. `Err(e)` prints `e.line()` (the MCP text, MS-19); `Local(n)` is the local send of `n`; `All` cannot come from a value with `@` and maps to `all`; `Remote(a)` is D3.
- D3. The remote sender is `pane.and_then(|k| ws.members.get(k)).and_then(|m| m.valid_name())` from the `workspace.json` read of this run (AU84); the CLI with no `ZYGO_PANE` has `None`, which `send_remote_with` refuses with the S§7.2 line. On `Ok(id)`: stdout `sent <id> to <name>@<host>` (the local `sent <id> to <label>` form), then `trigger(env, &ws.id, None, log)` with `log` writing `mail send: <text>` through `Store::log_error`; exit 0. A child that does not start keeps the send and exit 0 (the message is in the outbox; the next hook event or sync takes it), as MS-19 D4. Every refusal is its line on stderr and exit 1.
- D4. A config that does not load stops `zygo mail send` before any route with the existing `zygo mail: <error>` line and exit 11 (`user_config_or_exit`, unchanged). `read`, `ls` and `watch` load config only for a value with `@`, through `user_config`, and a load error makes the value not local (P1); a local listing never fails on config.
- D5. The `ls` address rule sits in `ls_text`, so `/zygo:mail ls <name>` (the same function) gets it; the slash form runs no git (config and files only).
- D6. The `watch` step (`watch_sync_step`) loads config once, before the loop; with `sync_for` not `Ok` (or a config that does not load) the step does nothing and `watch` is the ML-13 loop. Since review round 2 (F1) the gap is the S§8.4 rule of `spawn::trigger` on `mail/sync/last_start`, start to start, per workspace.
- D7. `twin_line` reads `state.json` only (no git, no lock); a missing or unreadable file gives no line, so `zygo doctor` still never fails (§8.2).

struct Fixed(SystemTime);
impl Clock for Fixed { fn now(&self) -> SystemTime { self.0 } }
/// A send runs no public check.
struct NoProbe;
impl Probe for NoProbe { fn probe(&self, _: &str) -> Verdict { panic!("a send runs no public check") } }
/// The spawn seam: each start records the number of outbox files at that moment; `fail` makes the start an error.
struct Spawns { sp: SyncPaths, seen: Arc<Mutex<Vec<usize>>>, fail: bool }
impl Spawner for Spawns {
    fn spawn_sync(&self, ws_id: &str) -> std::io::Result<()> {
        assert_eq!(ws_id, WS_ID);
        self.seen.lock().unwrap().push(pending(&self.sp).unwrap().len());
        if self.fail { Err(std::io::Error::other("seam: no child")) } else { Ok(()) }
    }
}
/// The wake seam: records the keys of each wake; the time is the fixed clock.
struct Woke(Arc<Mutex<Vec<Vec<String>>>>);
impl Wake for Woke {
    fn wake(&self, _: &Paths, _: &Workspace, keys: &[String], _: &MailConfig, now: SystemTime) {
        assert_eq!(now, at(T0));
        self.0.lock().unwrap().push(keys.to_vec());
    }
}

/// One machine with no remote: `Harness::no_tmux`, config `SYNC_ON` (host `a`), workspace `app` with ALICE `alice`,
/// ELENA `elena`, ANON (no name), and a member cache that holds `bob@b`.
struct X { h: Harness, w: Workspace, sp: SyncPaths, seen: Arc<Mutex<Vec<usize>>>, woke: Arc<Mutex<Vec<Vec<String>>>> }
fn setup() -> X {
    let h = Harness::no_tmux();
    std::fs::write(h.root().join("config.toml"), SYNC_ON).unwrap();
    let w = h.seed(WS_ID, &mut |w| {
        for (k, n) in [(ALICE, Some("alice")), (ELENA, Some("elena")), (ANON, None)] {
            w.members.insert(k.to_string(), MemberRecord { name: n.map(String::from), ..MemberRecord::new(Agent::ClaudeCode) });
        }
    });
    let sp = SyncPaths::new(&h.paths, WS_ID).unwrap();
    cache(&sp, &[("b", &["bob"])]);
    X { h, w, sp, seen: Arc::default(), woke: Arc::default() }
}
fn config(x: &X, text: &str) { std::fs::write(x.h.root().join("config.toml"), text).unwrap(); }
fn cache(sp: &SyncPaths, hosts: &[(&str, &[&str])]) {
    let mut c = MemberCache::default();
    for (h, ns) in hosts {
        c.hosts.insert((*h).into(), ns.iter().map(|n| (*n).to_string()).collect());
    }
    write_cache(sp, &c).unwrap();
}
/// The user config of `p`, as the binary loads it (`repo: None`).
fn cfg(p: &Paths) -> Config { zygo_config::load(&LoadContext { paths: p.clone(), repo: None, team: None }).unwrap().config }
fn env_of(x: &X, fail: bool, policy: DeadlinePolicy) -> Env {
    Env {
        paths: x.h.paths.clone(),
        clock: Box::new(Fixed(at(T0))),
        probe: Box::new(NoProbe),
        seam: Box::new(NoSeam),
        spawner: Box::new(Spawns { sp: x.sp.clone(), seen: Arc::clone(&x.seen), fail }),
        wake: Box::new(Woke(Arc::clone(&x.woke))),
        secret_policy: policy,
    }
}
/// `send_cli` from `pane` with SUBJECT and `body`: (exit code, stdout, stderr).
fn send_p(x: &X, pane: Option<&str>, to: &str, body: &str, fail: bool, policy: DeadlinePolicy) -> (i32, String, String) {
    let (mut o, mut e) = (Vec::new(), Vec::new());
    let code = send_cli(&env_of(x, fail, policy), &x.w, pane, to, SUBJECT, body, &cfg(&x.h.paths), &mut o, &mut e);
    (code, String::from_utf8(o).unwrap(), String::from_utf8(e).unwrap())
}
fn send(x: &X, pane: Option<&str>, to: &str, body: &str) -> (i32, String, String) { send_p(x, pane, to, body, false, far()) }
/// A refusal: exit 1, no stdout, `line` on stderr.
fn refused(r: (i32, String, String), line: &str) { assert_eq!(r, (1, String::new(), format!("{line}\n"))); }
fn spawns(x: &X) -> Vec<usize> { x.seen.lock().unwrap().clone() }
fn woke(x: &X) -> Vec<Vec<String>> { x.woke.lock().unwrap().clone() }
fn new_ids(x: &X, key: &str) -> Vec<String> {
    let Ok(rd) = std::fs::read_dir(mail_dir(&x.h.paths, WS_ID).join(key).join("new")) else { return Vec::new() };
    let mut v: Vec<String> = rd.map(|e| e.unwrap().path().file_stem().unwrap().to_string_lossy().into_owned()).collect();
    v.sort();
    v
}
fn errors(x: &X) -> String { std::fs::read_to_string(x.h.store(WS_ID).dir().join("errors.log")).unwrap_or_default() }
/// Nothing in `outbox/` or `outbox/tmp/`, and no child started.
fn nothing_sent(x: &X) {
    assert!(pending(&x.sp).unwrap().is_empty());
    assert!(!x.sp.outbox_tmp.exists() || std::fs::read_dir(&x.sp.outbox_tmp).unwrap().next().is_none());
    assert!(spawns(x).is_empty());
}
/// `zygo <args>` with `ZYGO_WORKSPACE = WS_ID` and `extra`.
fn zygo(h: &Harness, args: &[&str], extra: &[(&str, &OsStr)]) -> Output {
    let mut env = vec![("ZYGO_WORKSPACE", OsStr::new(WS_ID))];
    env.extend_from_slice(extra);
    h.zygo(args, &env).output().unwrap()
}
fn out(o: &Output) -> String { String::from_utf8_lossy(&o.stdout).into_owned() }
fn err(o: &Output) -> String { String::from_utf8_lossy(&o.stderr).into_owned() }
