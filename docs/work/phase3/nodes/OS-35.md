### Decisions (author)

1. **Id mask.** The token is `ZERO_ID`, 26 `0` (O§8.1). The id is the one name in `dir.results()` for which `zygo_results::is_id` holds (the listing of `shaping_hook.rs:65-69`). `run_case` asserts: at most one such name; with one, the hook stdout names it and does not name `ZERO_ID` before masking; `out` and `view` are the texts with each occurrence replaced by `ZERO_ID`. `Store::get` is read with the unmasked id.
2. **Run.** `run_case` builds a temporary session as `shaping_hook.rs:31-41` (`SessionView { session: "sess-1", agent, results: true, shape: true, trim_threshold_bytes: SessionView::default().trim_threshold_bytes, head_lines: 60, tail_lines: 20, ..Default::default() }`, a fresh usage db), `agent` = `Agent::OpenCode` when `meta.agent == "opencode"`, else `Agent::ClaudeCode`. It calls `guarded(&|b| trim::trim_in_with(&HookInput::parse(agent, b)?, &dir, &db, &opts), &serde_json::to_vec(&shaping::hook_input(c))?)` with `opts = TrimOpts { db_bound: zygo_usage::store::HOOK_DB_BOUND, stderr_cleared: trim::PO2_STDERR_CLEARED, shape_panic: false }` (explicit: `TrimOpts::default()` reads `ZYGO_TEST_SHAPE_PANIC`, `trim.rs:130`) and asserts exit code 0. A non-empty output must have `hookSpecificOutput.hookEventName == "PostToolUse"` (so a PO1 change fails here, naming O§7.13 item 5).
3. **Raw text** (O§7.2): OpenCode: `stdout` then `stderr` bytes (as `hook_input` joins them). Claude Code: `stdout`; when `stderr` is not empty, a `\n` if `stdout` is not empty and does not end in one, then `[stderr]\n`, then `stderr`. Store recovery is byte equality of `Stored.data` with this.
4. **Lines seen by the model**: the lines of `view`, plus the lines of `stderr_out` when it is a non-empty string (the PO2-fail branch keeps stderr, O§7.8). `holds(lines, m, log)` = some line equals `m`, or `log` and some line equals `format!("{n}: {m}")` for a decimal `n` (O§8.1, O§8.2). `log` = the row's shaper is `"log"`.
5. **Floors** (O§8.2), `meets(s, v, p)` = `(s - v) * 100 >= p * s` (integers, `s` = `stored_bytes`, `v` = `view_bytes` of the row, O§7.8 "as the row records them"):
   - `Clean`: `meets(.., 5)`; `!view.contains('\x1b')`; `!view.contains('\r')` unless reuse, where reuse = `command::parse(cmd).reuse || matches!(kind::sniff(&c.stdout), Kind::Diff | Kind::Json | Kind::Jsonl)` (O§7.3).
   - `DedupWarning`: `meets(.., 50)`; `dedup::expand(body) == cleaned`, where `body` is `view` after its first `\n` (the marker line, `view.rs:34-43`) and `cleaned` = `clean::clean(raw, reuse).map_or(raw, |(t, _)| t)`.
   - `LibtestPassing`: `meets(.., 80)`; each raw line that starts with `test result: ` is a view line.
   - `Failing`: `meets(.., 30)`.
   - `Capped`: `view_bytes <= VIEW_CAP_BYTES as u64`.
   - `NoChange`: `out == ""`, no row, nothing stored; each `must_keep` line is a line of the raw text (O§8.2 "the model gets each `must_keep` line in the raw text").
   - `NoRow` (`gotest/passing-verbose`, `pytest/passing`: O§8.2 has no row for a passing pytest or go test run): no floor; the other checks only.
   - Every row but `NoChange`: `out` not empty, one row, one stored id; `Stored.data == raw_text(c)`; each `must_keep` line `holds`; `stderr_out == Some("")` when `PO2_STDERR_CLEARED`, the agent is Claude Code and `c.stderr` is not empty.
   - Every row: the `must_keep` file neither starts with `\n` nor holds `\n\n` (an empty `must_keep` line makes the case invalid, O§8.1; `cases_in` drops empty items, so `problems` reads the file).
6. **Problem text.** Each problem starts `"{shaper}/{name}: "`. A missing line: `format!("{shaper}/{name}: must_keep line not in the view: {line:?}")`. A floor: `format!("{shaper}/{name}: saving {} of {s} bytes is under the {p} % floor (O§8.2)", s - v)`. An empty line: `format!("{shaper}/{name}: empty must_keep line (O§8.1)")`.
7. **Bless** (O§8.1 "Bless refuses"). `settle(c, f, g, bless)`: `p = problems(c, f, g)`; when `p` is not empty, return it and write nothing. Else with `bless`, write `g.view` to `c.dir.join("view")` and return none. Else compare the file's bytes with `g.view`: missing → `"{path}: missing; write it with ZYGO_BLESS=1 cargo test -p zygo-hooks --test shaping"`, different → `"{path}: differs from the hook view"`. Only `case_views_match_goldens` reads `ZYGO_BLESS` (`std::env::var("ZYGO_BLESS").as_deref() == Ok("1")`); every other test passes `bless` as a literal. No test sets a variable.
8. **Test-only shaper.** `hiding(g, line)` gives `g` with each `view` line equal to `line` removed (`view` re-joined with `\n`, keeping a final `\n` when it had one); row and store unchanged. It stands for "a shaper changed to hide a `must_keep` line" (O§16 item 1) without a production seam.
9. O§8.3 checks are OS-36's. When OS-36 lands, its checks join `problems` so bless also refuses on them (O§8.1); this node does not build them.
