# OS-20 — Capture pytest fixtures from a scratch project

**Spec:** `docs/specs/2026-11-24-output-shaping-design.md` O§8.1 "Real output" row `pytest`, O§8.1 "`must_keep`"
**Files:** `fixtures/shaping/pytest/passing/`, `fixtures/shaping/pytest/failing-verbose/`, `fixtures/shaping/pytest/collection-error/` (each folder holds meta.json, stdout, stderr and must_keep)
**Consumes:** `capture-shaping.sh` (OS-16)
**Produces:** the three case folders listed under Files
**Acceptance:** `cargo test -p zygo-hooks --test shaping_fixtures && test "$(ls -d fixtures/shaping/pytest/*/ | wc -l)" -ge 3` → at least 3 case folders exist (an empty folder fails), and tests pass; the listing shows the three cases; each `stdout` ends in a `=… in <n>s …=` summary line; `failing-verbose` was run with `-v`, has 2 failed tests and a non-empty `must_keep`; `collection-error` has an `ERRORS` section line in `must_keep`

## Plan

Notation: `W` is this worktree. `CAP` is `"$W/scripts/fixtures/capture-shaping.sh"` (OS-16). It writes `$W/fixtures/shaping/<shaper>/<case>/` and scrubs the run dir to `/repo`, `$HOME` to `/home/user`, and the user and host names to `user` and `host`. `S` is a fresh `mktemp -d` scratch dir under `TMPDIR` for each case, and the project is `$S/p`. `.gitattributes` already holds `fixtures/shaping/** -text`, and `fixtures/shaping/` does not exist yet on this branch. Each capture runs from `$S/p`, so pytest's `rootdir:` and module paths scrub to `/repo`. Probe of 2026-11-24: pytest 9.0.3 on Homebrew Python 3.14.6 at `/opt/homebrew/bin/pytest`, with no `plugins:` header line. The system `python3` (3.9.6) has no pytest. Probe results: `passing` exit 0, 48 passed; `failing-verbose` exit 1, 2 failed, 48 passed, stdout 5,236 B; `collection-error` exit 2, `1 error`. In all three, stderr is 0 B.

- [x] 1. Set the shell up once: `W=$(git rev-parse --show-toplevel); CAP="$W/scripts/fixtures/capture-shaping.sh"; export COLUMNS=80; unset PYTEST_ADDOPTS PYTEST_PLUGINS`. Then find pytest. Run `command -v pytest || PATH="/opt/homebrew/bin:$PATH"; command -v pytest`. If that still prints nothing, set `NEED_VENV=1`, and right after each `mkproj` (step 2) make a venv in that project with `python3 -m venv "$S/p/.venv" && "$S/p/.venv/bin/pip" install -q pytest && PATH="$S/p/.venv/bin:$PATH"` (this needs network access to PyPI). The venv lives under the run dir, so it scrubs to `/repo/.venv`, and pytest skips `.venv` when it collects. This changes no global Python, pip or git state. Check: `pytest --version` prints `pytest <x.y.z>`; `test "$COLUMNS" = 80`; `test -z "${PYTEST_ADDOPTS:-}"`. Step 3 checks that the header has no `plugins:` line.
- [x] 2. Write the shared project as a shell function, so that each case gets the same files: `mkproj() { S=$(mktemp -d) && mkdir -p "$S/p/tests" && cd "$S/p" && printf '%s\n' 'import pytest' '' '' 'def add(a, b):' '    return a + b' '' '' '@pytest.mark.parametrize("a", range(20))' 'def test_add(a):' '    assert add(a, 1) == a + 1' '' '' '@pytest.mark.parametrize("a", range(20))' 'def test_double(a):' '    assert add(a, a) == 2 * a' > tests/test_calc.py && printf '%s\n' 'import pytest' '' '' '@pytest.mark.parametrize("word", ["apple", "fig", "pear", "plum", "kiwi", "lime", "date", "yuzu"])' 'def test_upper(word):' '    assert word.upper().lower() == word' > tests/test_text.py; }`. Check: after `mkproj`, `pwd` is under `$TMPDIR`, and `ls tests` prints `test_calc.py test_text.py`.
- [x] 3. `pytest/passing`: `mkproj && ZYGO_CAPTURE_TOOL="$(pytest --version 2>&1)" "$CAP" pytest passing -- pytest`. must_keep stays empty, because no test fails (O§8.1 "`must_keep`"). Check in `$W/fixtures/shaping/pytest/passing`: `! grep -q "^plugins:" stdout` (if this fails, delete the folder and redo the case on the venv path of step 1); `tail -n 1 stdout | grep -Eq '^=+ 48 passed in [0-9.]+s =+$'`; `test ! -s must_keep`; `perl -MJSON::PP -0777 -ne 'exit !(decode_json($_)->{exit} == 0)' meta.json`.
- [x] 4. `pytest/failing-verbose`: `mkproj && printf '%s\n' '' '' 'def test_total():' '    assert add(2, 3) == 6' >> tests/test_calc.py && printf '%s\n' '' '' 'def test_plural():' '    assert "pear".upper() == "PEARS"' >> tests/test_text.py && ZYGO_CAPTURE_TOOL="$(pytest --version 2>&1)" "$CAP" pytest failing-verbose -- pytest -v`. Neither assertion prints an object address, so the text is the same on every run. Write must_keep with, for each failing test, its `FAILURES` name line and each `E` line of its assertion text (O§8.1 "`must_keep`"): `cd "$W/fixtures/shaping/pytest/failing-verbose" && grep -E '^_+ test_(total|plural) _+$|^E ' stdout > must_keep`. Check: `tail -n 1 stdout | grep -Eq '^=+ 2 failed, 48 passed in [0-9.]+s =+$'`; `grep -c ' FAILED ' stdout` is 2 (the `-v` progress lines); `wc -l < must_keep` is 9 (2 name lines, then 2 and 5 `E` lines, as probed); `grep -q '^E       assert 5 == 6$' must_keep`; `grep -q "^E       AssertionError: assert 'PEAR' == 'PEARS'$" must_keep`; `perl -MJSON::PP -0777 -ne '$m = decode_json($_); exit !($m->{exit} == 1 && $m->{command} eq "pytest -v")' meta.json`.
