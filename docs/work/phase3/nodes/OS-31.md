### Decisions (author)

1. **Regexes**, each a `static …: LazyLock<Regex>` in `runner.rs` beside the libtest ones. Within the O§7.6 forms (O§15 item 2: the builder writes the exact regex); each change against the literal form hides less.
   - `PY_SUMMARY` = `^=+ .*\b(passed|failed|error|errors|skipped)\b.* in [\d.]+s.* =+$` (verbatim; no `(?m)`, it is tested on one line).
   - `PY_PROGRESS` = `^\S+\.py [.sxX]+[ \t]*(\[[ \t]*[0-9]+%\])?$` (`\s` as ASCII space or tab, as OS-30 F4; `\d` as ASCII digit). The class has no `F` and no `E`.
   - `PY_VERBOSE` = `^\S+::\S+ (PASSED|SKIPPED|XFAIL|XPASS)([ \t].*)?$`. The literal tail `\b.*$` also matches `XPASS(strict)`, a failed test (review focus 18); the word must be followed by a space, a tab or the line end.
   - `PY_FAILURE` = `^=+ (FAILURES|ERRORS|short test summary info) =+$`, the header that opens a failure section.
2. **Summary on the last line.** `has_summary(Pytest, text)` = `PY_SUMMARY.is_match(last_line(text))`, with

   ```rust
   /// The last line of `text`, without the `\n` characters at its end (O§7.6 "a last line").
   fn last_line(text: &str) -> &str {
       text.trim_end_matches('\n').rsplit('\n').next().unwrap_or("")
   }
   ```

   So a text with a line after the summary (`[stderr]` and stderr text, a shell line) has no summary and gives `None` (O-C9: unsure, no change). A summary that ends in `\r` does not match.
3. **Failure section is sticky.** From the first `PY_FAILURE` line to the end of the text, no line is hidden. pytest prints all progress lines before its first section header, and the final summary line is the end, so on real output this equals the O§7.6 sections; it differs only where captured output inside `FAILURES` holds an `=` header followed by hidden-form lines, which the literal "to the next `=`-line header" would hide (built input `F`, test 7). Hides less only (O-C9).
4. **`hidden_by(Pytest, line)`** = `PY_PROGRESS.is_match(line) || PY_VERBOSE.is_match(line)`, after the shared `\r` and counted-form guard at `runner.rs:37-39`.
5. **`pytest(text)`**:
   - `None` when `!has_summary(Runner::Pytest, text)`.
   - One pass over `text.split_inclusive('\n')`, bare line = the line less one trailing `\n`. A bare line matching `PY_FAILURE` sets the failure flag (never cleared). A line is hidden when the flag is not set and `hidden_by(Runner::Pytest, bare)`; every other line is kept verbatim, in order.
   - One count line `[zygo: <n> passed or skipped progress lines hidden]\n` at the place of the first hidden line, `<n>` = all hidden lines of the text (O§7.6 row `pytest`, "at the place of the first one").
   - `None` when no line is hidden, or when the view is not strictly shorter than `text` (O§7.3, as `libtest`).
   - Else `Some((view, vec![Step::PassedTestsHidden]))`.
6. **Dispatch unchanged** (O§7.6, OS-30 Decision 6): `view` maps `Runner::Pytest` to `pytest(text).map(|(v, s)| (v, s, Shaper::Pytest))`; the first runner with its summary decides, and its `None` is final. `Gotest` stays `false`/`None` (OS-32).
7. **Open point for the lead (not changed here).** Under a wrapper (`make test`, order `[Libtest, Pytest, Gotest]`), pytest output whose `FAILURES` section captured a `cargo test` run holds a `test result:` line, so libtest is chosen (`runner.rs:57`), and the libtest failure flag knows only `---- ` / `failures:` (`runner.rs:89-93`). The libtest view then hides captured `test x ... ok` and cargo progress lines inside a pytest failure section, the same class as OS-30 F1. No fixture has it. The plan pins the order only on a text with no such capture (`M`, test 12); a fix changes the O§7.6 dispatch rule and belongs to a spec change and its own node (§5.4).

use Step::PassedTestsHidden as Passed;

static COUNT: LazyLock<Regex> =
    LazyLock::new(|| Regex::new(r"^\[zygo: (\d+) passed or skipped progress lines hidden\]$").unwrap());

const CASES: [&str; 3] = ["passing", "failing-verbose", "collection-error"];
const SUMMARY_PASSING: &str = "============================= 128 passed in 0.04s ==============================";
const FAILURES: &str = "=================================== FAILURES ===================================\n";
const ERRORS: &str = "==================================== ERRORS ====================================\n";

/// The O§7.2 raw text and the `must_keep` lines of a case under `fixtures/shaping/<dir>/<name>/`.
fn case_in(dir: &str, name: &str) -> (String, Vec<String>) {
    let p = PathBuf::from(env!("CARGO_MANIFEST_DIR")).join("../../fixtures/shaping").join(dir).join(name);
    let read = |f: &str| String::from_utf8(std::fs::read(p.join(f)).unwrap()).unwrap();
    let (so, se) = (read("stdout"), read("stderr"));
    let mut raw = so.clone();
    if !se.is_empty() {
        if !so.is_empty() && !so.ends_with('\n') {
            raw.push('\n');
        }
        raw.push_str("[stderr]\n");
        raw.push_str(&se);
    }
    let keep: Vec<String> = read("must_keep").lines().map(String::from).collect();
    assert!(keep.iter().all(|l| !l.is_empty()), "{dir}/{name}: an empty must_keep line is invalid");
    (raw, keep)
}
fn case(name: &str) -> (String, Vec<String>) { case_in("pytest", name) }
fn bare(l: &str) -> &str { l.strip_suffix('\n').unwrap_or(l) }
/// The raw lines the view removed (O§8.3 item 5): one cursor over the view lines that are not count lines;
/// a raw line equal to the line at the cursor is kept, any other raw line is removed; every view line is used.
fn removed<'a>(raw: &'a str, view: &str) -> Vec<&'a str> {
    let kept: Vec<&str> = view.split_inclusive('\n').map(bare).filter(|l| !COUNT.is_match(l)).collect();
    let (mut i, mut out) = (0, Vec::new());
    for l in raw.split_inclusive('\n').map(bare) {
        if kept.get(i) == Some(&l) {
            i += 1;
        } else {
            out.push(l);
        }
    }
    assert_eq!(i, kept.len(), "a view line is not a raw line in order: {:?}", kept.get(i));
    out
}
fn saving(raw: &str, view: &str) -> f64 { 1.0 - view.len() as f64 / raw.len() as f64 }
