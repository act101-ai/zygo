# FX-32 — The P and Q arms of `check-premises.sh` refuse a dated note whose text holds `)`

**Spec:** docs/specs/2026-11-18-zygo-design.md §19 ("A failed premise applies its fallback, recorded as a dated note in this document"; the P notes `*(Note YYYY-MM-DD, N2, Pn: …)*`, and for P6a also §10.5) and §19a (the Q notes `*(Note YYYY-MM-DD, N2, Qn: …)*`). Found by the SX-10 review (F5); the defect was there before SX-10: the `P*)` and `Q*)` arms and the P6a check of `scripts/check-premises.sh` match the note with `[^)]*\)\*` (the `pat` variable), so a note whose text holds `)` never matches, and a failed P or Q row with such a note is refused. The ST arm already matches to the closing `)*` (SX-10 review F5).
**Files:** `scripts/check-premises.sh`, `scripts/premises/ver_test.sh`
**Consumes:** —
**Produces:** —
