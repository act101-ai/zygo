# FX-46 — `git_bound_is_total` runs its child test

**Spec:** — (test defect, found in the FX-43 work, 2026-11-28). `crates/zygo-config/tests/config_layers.rs:885-913`: `git_bound_is_total` is `#[ignore]` (timing) and runs itself again in a child process with a fake `git` on `PATH` (`:905-910`, args `git_bound_is_total --exact --test-threads=1`).
