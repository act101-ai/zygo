### Author's calls

1. Golden layout: one folder for each input under `crates/zygo-hooks/tests/golden/shape_off/`, at `shaping/<shaper>/<case>/`, `claude-code/<file stem>/` or `opencode/tool.execute.after-bash/`. The folder holds `hook_stdout` (the hook stdout with the stored id replaced by 26 `0`, and empty when there is no output) and `stored` (the raw file bytes; the file is absent when nothing was stored). Two plain files keep the review diff readable.
2. A "Bash fixture" of `fixtures/claude-code/hooks/` is a `*.json` file whose stem has `Bash` as its second `-` field. An input whose event is `PostToolUseFailure` (shaping `meta.event`, or the hook fixture's `hook_event_name`) must give empty stdout and store nothing. It has no golden.
3. Each input runs in its own temporary session dir with `SessionView { session: "sess-1", agent, results: true, shape: false, ..Default::default() }`. `agent` is `OpenCode` when `meta.agent == "opencode"` or for the OpenCode fixture, else `ClaudeCode`.
4. Bless: when `ZYGO_BLESS` is `1`, the test writes `hook_stdout`, writes `stored` or removes a stale one, and passes. Otherwise a missing or different file is a problem. The test collects every problem and fails once, with each golden path named.

  ```rust
  fn run_off(agent: Agent, input: &[u8]) -> Got {
      let t = tempfile::tempdir().unwrap();
      let dir = SessionDir::new(t.path().join("s"));
      dir.create().unwrap();
      SessionView { session: "sess-1".into(), agent, results: true, shape: false, ..Default::default() }.save(&dir).unwrap();
      assert!(!SessionView::load(&dir).unwrap().shape);
      let db = t.path().join("usage.db");
      let (out, code) = guarded(&|b| trim::trim_in_with(&HookInput::parse(agent, b)?, &dir, &db, &TrimOpts::default()), input);
      assert_eq!(code, 0);
      let ids: Vec<String> = std::fs::read_dir(dir.results()).map(|d| d.map(|e| e.unwrap().file_name().to_string_lossy().into_owned())
          .filter(|n| zygo_results::is_id(n)).collect()).unwrap_or_default();
      assert!(ids.len() <= 1, "{ids:?}");
      match ids.first() {
          Some(id) => Got { stdout: out.replace(id.as_str(), &"0".repeat(26)), stored: Some(std::fs::read(dir.results().join(id)).unwrap()) },
          None => Got { stdout: out, stored: None },
      }
  }
  /// Compares `got` with `GOLDEN/rel/{hook_stdout,stored}`, or writes them under `ZYGO_BLESS=1`; returns each problem, naming the path.
  fn check(rel: &str, got: &Got) -> Vec<String>
  /// An input whose event is `PostToolUseFailure`: empty stdout and nothing stored.
  fn empty(rel: &str, got: &Got) -> Vec<String>
  fn agent_of(c: &shaping::Case) -> Agent   // OpenCode when meta.agent == "opencode"
  ```

          let rel = format!("shaping/{}/{}", c.shaper, c.name);
          let got = run_off(agent_of(c), &serde_json::to_vec(&shaping::hook_input(c)).unwrap());
