# FX-16 — Clean removes charset designations (`ESC ( B`) and the escape after a lone `ESC` (`ESC ESC [31m`)

**Spec:** `docs/specs/2026-11-24-output-shaping-design.md` O§7.4 bullet 1 (charset designation `ESC (` / `ESC )` plus one final byte `0x30-0x7E`, 3 bytes; when the next byte is not such a byte, only `ESC (` / `ESC )` goes; a lone `ESC` at the text end, before a line end or before another `ESC` is removed alone), O§15 item 2, O-C9; change log line 2026-11-25 O§7.4; findings F4 and F5 of the OS-12 review. ### Decisions (author)

1. Charset designation (lead, review round 2 F1): `ESC (` or `ESC )` followed by one final byte in `0x30-0x7E` (ECMA-35) removes the `ESC`, the `(`/`)` and that byte, 3 bytes in all. Any other next byte (a non-ASCII character, `U+009B`, a byte below `0x30`) stays, and only `ESC (`/`ESC )` goes (O-C9: when a shaper is unsure, it keeps). A 2- or 3-byte cut ends on an ASCII byte, so it stays on a UTF-8 boundary.
2. `ESC (` or `ESC )` at the text end, or before `\n` or `\r`, removes only `ESC (`/`ESC )` (an escape never takes `\n` or `\r`, OS-12 Decision 2). Before `ESC`, it also removes only `ESC (`/`ESC )`, and that `ESC` starts its own sequence (same reading as the lone-`ESC` rule; nothing of the next sequence stays as residue). None of these bytes is in `0x30-0x7E`, so Decision 1 gives this.
3. `ESC` followed by `ESC` removes only the first `ESC` (1 byte); the loop in `strip_escapes` then reads the second `ESC` as the start of its own sequence.
4. No signature changes: `fn esc_len(text: &str, i: usize, osc_stop_cache: &mut Option<usize>) -> usize` gets two new match arms before `Some(_)`.
