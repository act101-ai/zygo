### Lines (author's calls within R§10 and R§17)

In this order, each through `esc` where it holds repository or user text:
1. Only when `checkout(cwd, now + 2 s)` finds a checkout (outside a repository there are no workspace files, so no line). `Use` of `check_default(&co.top, &workspace_id(&co.common_dir), approvals, git)`:
   - `Approved`: `workspace files: <full_ref> <pin.commit[..12]> digest <short(pin.digest)>: approved`
   - `NotApproved`: `workspace files: <full_ref> <files.commit[..12]> digest <short(digest)>: not approved`
   - `Invalid`: `workspace files: invalid (<why>)`; `Absent`: `workspace files: none`; `Unread`: `workspace files: unread (<why>)`.
2. `Approved` or `NotApproved`, `repository_loadout(&def)` is `Some`, `merged.config.loadout` has no `repository` key (a user loadout of that name is used in its place, R§10 `up` row), and its agent panes (`kind != "shell"`, all windows) number `n > merged.config.limits.max_members`: `workspace files: <n> agents; [limits] max_members is <m>`. Not-approved files get the line too, so the operator learns it before approving.
3. `merged.config.workspace.pool` is `Some(text)`: `expand(text, pool::home().as_deref())`, then `list`; `pool: <dir>: <k> directories`, else `pool: <dir>: <reason>`. `<dir>` is the expanded path, or `text` when `expand` fails.
4. `list` gave `k` directories: the shared lines of the loadout `up` would choose (R§10 `up` row, no `--loadout`): `merged.config.workspace.default_loadout` when `merged.source_of("workspace.default_loadout") == Layer::User`; else `repository` when the use is `Approved` and `def.workspace` is `Some`; else `solo`. Look the name up in `merged.with_definition(&def).config.loadout` when `Approved`, else in `merged.config.loadout`; `solo` not there is `builtin_solo()`; an unknown name gives no line. Pool members are its panes with `pool && kind == "claude-code"`, in pane order over all windows; `assign(&names, k)` gives each its directory; the `dir_of` label is the pane `name`, or `pane <i>` (1-based pane index in the loadout) for an unnamed pane. Append `shared_lines(&dir_of)`.
