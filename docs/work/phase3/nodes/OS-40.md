### Decisions (author)

1. Bare shell stage: a `bash`, `sh` or `zsh` stage whose index in its pipeline is above 0 (it is after a `|`) and that has no `-c` flag (by the existing flag rule) sets `acc.unsure`. Command words after `xargs` and `find -exec` count as index 0, so `ls | xargs bash` is not bare (`xargs` passes the words as script file names).
2. `$(<f)`: a `$(` whose next character, after spaces and tabs, is `<`, and the character after that `<` is neither `<` nor `(`. The nested script is then marked `reads`, and `visit` sets `acc.file_printer` for it. Backticks are not in the scope.
3. `eval`: the texts of the words after `eval` (after quote removal, as stored in `Word.text`) are joined by single spaces and passed to `nest`, the same call that `-c` uses. A dynamic word keeps its raw text, so `eval $CMD` lexes a dynamic program word and is unsure.
4. `timeout` options that take an argument: `-k`, `-s`, `--kill-after`, `--signal`; one operand (the duration) is skipped after the options. `stdbuf` options that take an argument: `-i`, `-o`, `-e`, `--input`, `--output`, `--error`; no operand. `--signal=KILL` and `-oL` stay one word, as `opt` already handles.
5. `timeout` and `stdbuf` join `LISTED_WRAPPERS`, because O§7.2 now lists them: `timeout 60 cargo test` records `cargo test` and runners `[Libtest]`.
