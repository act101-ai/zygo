### Decisions (author)

1. Order: escapes first, then `\r`. The diff fixture has `\r` before `ESC[m`: `\r`-first keeps `ESC[m` as the text after the last `\r`, and the line loses `+x`. Test `escapes_go_before_carriage_returns`.
2. Line rule (O§7.4 "Clean removes no line"; acceptance "output line count equals input line count"): an escape never takes `\n`. `ESC` before `\n` or `\r` removes only the `ESC` (so `reuse = true` keeps each `\r`). An OSC body that reaches `\n` before `BEL` or `ESC \` has no terminator. This is the reading of the third O§7.4 bullet over the first; it hides less. Flagged to the lead in the report.
3. OSC with no terminator, any length: it does not match the OSC form (`ESC ]` to `BEL` or `ESC \`), so "any other `ESC` plus its next character" applies: only `ESC ]` goes. For more than 4 KiB that is the O§7.4 text word for word; for less, it is the same form, and nothing after the `ESC ]` is eaten (graph review focus 27).
4. A CSI with no valid final byte is not a CSI: `ESC [` goes by the "other `ESC`" form. A `U+009B` with no valid tail stays (O§7.4 has no "other" form for it; O-C9: when unsure, keep).
5. `\r\n` → `\n` is part of the `\r` bullet, so it gives `ProgressLinesRemoved`. Steps are in pipeline order: `ColorCodesRemoved` then `ProgressLinesRemoved`; each one only when its pass changed the text. `None` when no pass changed it.
6. `\r` rule per line, after `\r\n` → `\n`: split on `\n`, keep the text after the last `\r`, join with `\n`.
7. Time bound: the OSC scan of one line runs at most once. When a scan from `i` finds no terminator before the line end `e`, a later `ESC ]` before `e` does not scan again. So a 400,000-character line of `ESC ]` (O§8.3 built input) is linear.
8. The form `ESC ( B` is planned as O§7.4 gives it (`ESC (` goes, `B` stays). See the report: the cargo fixture shows that this form is wrong.

  use zygo_results::shape::{Step::{self, *}, clean::clean};

  /// Runs clean and checks the line count on every input (acceptance: lines kept).
  fn run(input: &str, reuse: bool) -> Option<(String, Vec<Step>)> {
      let r = clean(input, reuse);
      if let Some((out, _)) = &r {
          assert_eq!(out.matches('\n').count(), input.matches('\n').count(), "lines: {input:?}");
