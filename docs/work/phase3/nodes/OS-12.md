# OS-12 — Clean step: ANSI escapes and carriage-return progress

**Spec:** `docs/specs/2026-11-24-output-shaping-design.md` O§7.4, O§7.3 "Text that the model may reuse" (escapes only), O-C9
**Files:** `crates/zygo-results/src/shape/clean.rs`, `crates/zygo-results/src/shape/mod.rs`, `crates/zygo-results/tests/shape_clean.rs`
**Consumes:** `Step` (OS-10)
**Produces:** `clean::clean(text: &str, reuse: bool) -> Option<(String, Vec<Step>)>` (`None` = no change; the steps are `color codes removed`, `progress lines removed`, or both)
**Acceptance:** `cargo test -p zygo-results --test shape_clean` → all pass: CSI, the 8-bit CSI `U+009B`, OSC ended by `BEL` and by `ESC \` are removed; OSC 8 keeps its visible text; an OSC over 4 KiB with no end loses only `ESC ]`; a lone trailing `ESC` is removed; any other `ESC` plus its next character is removed; `a\r\nb` gives `a\nb`; `10%\r50%\r100%` gives `100%`; with `reuse = true` each `\r` stays and only escapes go; the output line count equals the input line count for each test input; text with nothing to clean gives `None`
