# FX-37 — Session-folder file safety in pre-compact and overrides

**Spec:** `docs/specs/2026-11-24-session-text-design.md` T§9.2 item 1, T§14 item 2, T-C1, T-C6 and the state-modes constraint (found in the Phase 3 final verification stage, 2026-11-28, head b628e1ad). **SX-F1.** `crates/zygo-hooks/src/pre_compact.rs:48-67` `create_flag`: no link check on `reinject/` (`set_permissions(0700)` at `:58` follows a link to another folder); the flag is opened without `O_NOFOLLOW` or `O_NONBLOCK` (`:59-63`), so a link to a file gets chmod 0600 (`:65`) and a FIFO blocks the hook (`timeout 5 zygo hook pre-compact` → 124). The FX-9 code refuses the same hazards (`crates/zygo-hooks/src/session_start.rs` `read_item` at :158, `O_NOFOLLOW | O_NONBLOCK`; `store_item` at :189, `folder_state` link check at :198). **SX-F2.** `crates/zygo-core/src/overrides.rs:27-29` `Overrides::load` uses `std::fs::read` with no type or size check; a FIFO at `overrides.json` hangs SubagentStart and `--event subagent` (exit 124). Callers: `crates/zygo-hooks/src/session_start.rs:70`, `crates/zygo-hooks/src/trim.rs:281`. FIX-22 made `SessionView::load` refuse a FIFO (`crates/zygo-core/src/session_view.rs:192-229`: `O_NONBLOCK` open, `<path>: is a FIFO`, no size cap). **SX-F3.** `pre_compact.rs:34` `let out = run_in(dir)?;` returns `Err` before the flag is made when the work folder cannot be read (`open_units`, `:70-75`); T§9.2 item 1 does not make the flag depend on the units read; T§14 item 2.
