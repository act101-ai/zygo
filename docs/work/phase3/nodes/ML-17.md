- `live-mail.sh --pm` scrubs and writes the fixtures itself: `finish` (`workspace_lib.sh:53-65`) writes `<record>.out` (head line + sub-check lines), runs `scrub` = `python3 -I scripts/premises/scrub.py "$RUN" <file>` (`lib.sh:123-125`) and prints one `LIVE` line; `oc_fx` (`live-mail.sh:420-421`) does the same for the OpenCode lines; `cpfx` (`live-mail.sh:423-424`) copies the five fixtures into `fixtures/claude-code/mail/` and `fixtures/opencode/mail/` of the checkout that holds the script (`REPO_DIR`, `lib.sh:9`; `live-mail.sh:152`).   - `/tmp/ml17-pm/live-*/ml-rec/PM1.txt`, `PM2.txt`, `PM3.txt` (sub-check lines only), `PM<n>.bad` (failed sub ids, only when one failed)
  - `/tmp/ml17-pm/live-*/fx-claude-code/pm1.txt`, `pm2.txt`, `pm3.txt` and `/tmp/ml17-pm/live-*/fx-opencode/pm2.txt`, `pm3.txt` (scrubbed copies before `cpfx`)
