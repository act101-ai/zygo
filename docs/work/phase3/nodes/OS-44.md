# OS-44 — Read-back bytes count what the agent kept, not the reply sent

**Spec:** `docs/specs/2026-11-24-output-shaping-design.md` O§6.4 (read-back size, the known limit), O§17 PO4 (the agents' cut limits: OpenCode 51200 bytes or 2000 lines; Claude Code `MAX_MCP_OUTPUT_TOKENS`, default 25000 tokens)

**Consumes:** `Readbacks::new` (OS-5), `results::tools_with` (OS-5): the read-back write from OS-5, Readbacks::record (crates/zygo-mcp/src/tools/results.rs:27-48; the row's bytes is reply.len() at :34), called by reply (:67-72) for each successful result_view, result_search and result_tree reply
**Produces:** —
**Acceptance:** `env -u ZYGO_SESSION_DIR cargo test -p zygo-mcp --test readbacks` → all pass; the case that proves the fix is set by the plan; a fix that adds a cap or threshold needs operator approval before it is planned

Found at OS-26 close. The row records the byte count of the reply the MCP server sends. An agent cuts an MCP reply above its own limit (O§17 PO4), and `result_view` limits only lines (`MAX_RANGE_LINES` = 400), not bytes (`crates/zygo-results/src/store.rs:111-124`). So for a reply above the agent's limit, the read-back figure counts more bytes than the agent's context got.

### Rule (the algorithm the signature leaves open)

`kept_bytes(agent, reply)` is the byte count of the part of `reply` that the agent keeps (O§17 PO4); the agent's own truncation note is not counted:

- `Agent::ClaudeCode`: `min(reply.len(), CLAUDE_CODE_CUT_TOKENS * BYTES_PER_TOKEN)` = `min(reply.len(), 100_000)`.
- `Agent::OpenCode`: `head` = `reply` when `reply.lines().count() <= 2000`, else `reply[..i]` where `i` is the byte index of the 2000th `b'\n'`; result `min(head.len(), 51_200)`.

Constants, private in `results.rs`, each with a doc line citing O§17 PO4: `const CLAUDE_CODE_CUT_TOKENS: u64 = 25_000;` `const OPENCODE_CUT_BYTES: u64 = 51_200;` `const OPENCODE_CUT_LINES: usize = 2_000;`. Use `zygo_core::tokens::BYTES_PER_TOKEN`; do not add a new 4.

  ```rust
  /// 400 lines of `w - 1` bytes of `x`, each ended by `\n`: a default `result_view` reply of 400 × w − 1 bytes.
  fn wide(w: usize) -> String {
      (0..400).map(|_| format!("{}\n", "x".repeat(w - 1))).collect()
  }

  fn tools_for(e: &Env, agent: Agent) -> Vec<Box<dyn Tool>> {
      tools_with(e.dir.clone(), Some(Readbacks::new(e.db.clone(), READ_IN.into(), zygo_usage::store::HOOK_DB_BOUND, agent)))
  }

  /// The case that proves the fix (OS-44; O§6.4, O§17 PO4): a reply above the agent's cut counts the cut, not the reply.
  #[test]
  fn readback_above_the_agent_cut_counts_the_bytes_the_agent_kept() {
      for (w, agent, want) in [
          (300, Agent::ClaudeCode, 100_000), // reply 119_999 > 25_000 tokens × 4
          (300, Agent::OpenCode, 51_200),
          (200, Agent::ClaudeCode, 79_999),  // below Claude Code's cut: the whole reply
          (200, Agent::OpenCode, 51_200),    // above OpenCode's byte cut
      ] {
          let e = env();
          let s = zygo_results::Store::put(&e.dir, "Bash", Some(TRIM), wide(w).as_bytes()).unwrap();
          let t = tools_for(&e, agent);
          let reply = call(by_name(&t, "result_view"), json!({"id": s.id})).unwrap();
          assert_eq!(reply.len(), 400 * w - 1, "{agent:?} w={w}"); // the reply is sent whole (O-C1)
          let r = rows(&e.db);
          assert_eq!(r.len(), 1, "{agent:?} w={w}");
          assert_eq!(r[0].5, want, "{agent:?} w={w}");
      }
  }

  #[test]
  fn kept_bytes_applies_each_agent_cut_of_o17_po4() {
      let lines = |n: usize, w: usize| vec!["a".repeat(w); n].join("\n");
      assert_eq!(kept_bytes(Agent::OpenCode, ""), 0);
      assert_eq!(kept_bytes(Agent::OpenCode, &lines(2000, 2)), 5_999); // 2000 lines: whole
      assert_eq!(kept_bytes(Agent::OpenCode, &lines(2001, 2)), 5_999); // 2001 lines: the first 2000
      assert_eq!(kept_bytes(Agent::ClaudeCode, &lines(2001, 2)), 6_002); // no line cut on Claude Code
      assert_eq!(kept_bytes(Agent::OpenCode, &lines(2001, 30)), 51_200); // line head 61_999 > byte cut
      assert_eq!(kept_bytes(Agent::OpenCode, &"a".repeat(51_200)), 51_200);
      assert_eq!(kept_bytes(Agent::OpenCode, &"a".repeat(51_201)), 51_200);
      assert_eq!(kept_bytes(Agent::ClaudeCode, &"a".repeat(100_000)), 100_000);
      assert_eq!(kept_bytes(Agent::ClaudeCode, &"a".repeat(100_001)), 100_000);
  }
  ```
