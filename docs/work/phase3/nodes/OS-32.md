Spec drift, reported to the lead (not edited here; the spec is outside Files):

1. O§7.6 "Failure section … go test: every line from the test's `=== RUN <name>` to its `--- FAIL: <name>` line and the indented lines after it". Read literally, for a parent of parallel subtests (`TestGroup` in `failing-parallel`, `:2` to `:112`, then `:113-125`) this keeps every passing subtest's lines, against O§16 item 4 and this node's Acceptance ("no line of a passing test is"). This plan reads the failure section as the lines that rules 1-2 give to the failing test (the section's own last clause), and a result line always belongs to the test it names, also inside another test's indented block (Decision 2).
2. Rule 1 does not say when a current test ends. Read literally, a line after a package's `ok`/`FAIL` summary line (a build error of the next package, the `[stderr]` part of O§7.2) belongs to the last test of the previous package and is hidden when that test passed, against O-C9. Decision 2 ends the current test at a summary line and at `[stderr]`. This hides less (O§15 item 2).
3. Rule 1 keys tests by name only; `go test ./...` can run the same name in two packages. Decision 2 keys a test by package block and name. This hides less.

### Decisions (author)

1. **Forms** (O§7.6, O§15 item 2; `\s` = `[ \t]`; each a `static …: LazyLock<Regex>` next to the pytest statics in `runner.rs`):
   - `GO_SUMMARY` = `(?m)^(ok|FAIL|\?)[ \t]+\S` (the summary that confirms; `(?m)` as `SUMMARY` at `runner.rs:12-13`, so it tests a whole text and one line).
   - `GO_NO_TESTS` = `^\?[ \t]+\S+[ \t]+\[no test files\]$` (the hidden form).
   - `GO_MARK` = `^=== (RUN|PAUSE|CONT|NAME)[ \t]+(\S+)$` (rule 1; group 2 the name).
   - `GO_RESULT` = `^[ \t]*--- (PASS|FAIL|SKIP): (\S+) \(.*\)$` (rule 2; group 1 the result, group 2 the name).
   - `GO_PACKAGE` = `^((ok|FAIL|PASS)([ \t].*)?|panic:.*|exit status .*)$` (rule 4).
   - Arms: `hidden_by(Gotest, l)` = `GO_NO_TESTS.is_match(l)` after the shared guard at `:64-66`; `has_summary(Gotest, t)` = `GO_SUMMARY.is_match(t)`; `view` `Gotest` arm = `gotest(text).map(|(v, s)| (v, s, Shaper::Gotest))`.
2. **Grouping** (rules 1-4; the tests do not decide it alone). A private `fn go_lines(text: &str) -> Vec<GoLine>` with a private `enum GoLine { Passed, Kept, Free }`, one entry per `split_inclusive('\n')` line. One pass; state: `pkg: usize` (package block, starts at 0), `cur: Option<(usize, &str)>` (current test), `open: Vec<((usize, &str), usize)>` (open result blocks: test key and the result line's indent), `owner: Vec<Option<(usize, &str)>>`, `passed: HashMap<(usize, &str), bool>` (true while every result of that key is `PASS` or `SKIP`). For each line, `bare` = the line without `\n`, `depth` = count of leading spaces and tabs, `cr` = `bare` ends in `\r`:
   1. Pop every open block whose indent is `>= depth` (rule 2 "to the next line with less or equal indentation").
   2. `bare == "[stderr]"`, or `GO_SUMMARY` matches and `bare` does not start with `?` (an `ok`/`FAIL` package summary): owner `None`; `pkg += 1`; `cur = None`; `open.clear()`.
   3. Else `GO_SUMMARY` matches with `cur == None` (a `?` package line), or `GO_PACKAGE` matches: owner `None` (rule 4).
   4. Else not `cr` and `GO_MARK` matches: `cur = Some((pkg, name))`; owner `cur` (its `===` lines belong to it).
   5. Else not `cr` and `GO_RESULT` matches: key `(pkg, name)`; `passed[key] &= result != FAIL` (insert `result != FAIL` when absent); push `(key, depth)` on `open`; owner `Some(key)` (a result line belongs to the test it names, also inside an open block).
   6. Else the line, less its leading blanks, starts with `=== ` or `--- `: owner `None` (rule 1 gives such a line to no test).
   7. Else owner = the key of the last open block, else `cur` (rule 2 before rule 1). A `?` line printed while a test is current falls here, so a `[no test files]` line printed by a failing test stays (O-C9).
   After the pass: `Passed` when the owner's `passed` entry is `true` and the line does not end in `\r` or match `COUNTED` (the OS-30 guard: such lines are never hidden); `Kept` for any other line with an owner (a `FAIL` result or no result line: rule 3); `Free` for owner `None`.
3. **View** (`gotest`, the shape of `pytest` at `runner.rs:181-216`): `None` unless `has_summary(Gotest, text)`. Hide each `Passed` line and each `Free` line for which `hidden_by(Gotest, bare)`; keep every other line verbatim and in order. Write `[zygo: <n> lines of passed tests hidden]` at the place of the first hidden `Passed` line and `[zygo: <n> packages with no test files hidden]` at the place of the first hidden `[no test files]` line (the O§7.6 count-line wording; place as in the libtest and pytest rows). `None` when nothing is hidden or the view is not shorter than `text` (O§7.3). Steps: `vec![Step::PassedTestsHidden]` (the fixed O§7.8 set has no other step for this view).
4. **`gotest_passed_lines`** = the 1-based indices of the `Passed` entries of `go_lines(text)`.

#[test]

    }
