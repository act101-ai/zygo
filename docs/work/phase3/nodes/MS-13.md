### Author's calls

- **Exit codes.** S§8.3 gives exit 0 for a child only at the gate and the lock; every other stop is exit 1 in both modes (S§7.5, S§8.3 steps 7 and 15).
- **The look uses `exists`.** A look that deleted the mark and then failed the lock would drop a mark that no holder sees; only step 4, under the lock, deletes it.
- **Who logs.** `run` writes the `errors.log` line of each stop in both modes, with the check name only; the CLI line goes back in `SyncError::Stopped.line` for MS-17 to print. This keeps a line that names another workspace out of the log (focus 51).
- **Ack per host.** A ULID goes into the ack of each own host whose folder holds it at the tip, and leaves it when no such file remains (focus 47). The current host's ack is written when it is absent, so the host stays an own host after a rename (S§7.6 "Rename": "The old `ack/<old>.json` stays, so the old host stays an own host").
- **Pending blob ids** come from `read_meta` of the new commit (no hash computed in this crate, so the object format of the repository does not matter).
- **Config.** The sync loads layers 1-4 with the main worktree as the repository, so the `[redaction]` patterns of S§8.6 are the workspace's merged ones; `[mail]` comes only from user config (`USER_ONLY`, `zygo-config/src/layers.rs:70`).
