### Drift and decisions (cited)

- P1 (R§7.4 bullet 2 and R§12 row rewritten; change log 2026-11-26). The pin of a repository-loadout member is written by `up` into the fresh record at the build (`up.rs:697`, WD-12), not by the callback. The callback's start write keeps it, because `ws run` passes `MemberCtx.launch = rec.launch.clone()` (`cmd/ws.rs:286`) and `record_start` copies that launch whole. So `launch.job` and `launch.definition` already survive a `ws run` resume (the WD-8 note, `docs/work/phase3/nodes/WD-8.md:108`); U4 and B1 hold it.
- P2 (the gap this node closes). `ws run` does not pass the pin: `launch_of` and `launch_open_code_of` (`ws.rs:450-475`) build `cmd::Launch` without it, and the launcher always calls `check_default` (`launcher.rs:886`), so a resume reads the default branch again (review focus 33).
- P3 (R§7.4 bullet 5 rewritten). "With the R§6.1 reason in place of `no longer has or no longer approves`" gives no clear line. Final text: `…, which were not read (<why>); the agent was not started; …`, `<why>` escaped: the words of the R§8 not-read line.
- D1. Stop: the launcher prints the line through `out` and returns 1. The profile step (`launcher.rs:336-372`) runs before the proxy, the session and the callback (`:387` onward), so nothing writes the record (AU92), and `ws run` prints the W§8.2 `NotStarted` line (`member.rs:682`) and opens the shell. Exit 1 is written into R§7.4.
- D2. The saved commit and digest pass `esc` after `short` in the line: the state file is not trusted text (C6, R-C7).
- D3. An approved pinned read with no profile of the requested name gives the R§8 not-found line, and the launch goes on. A launch folder with no checkout (no common dir) gives the `NO_LONGER` stop. Both are written into R§7.4.
- D4. `definition_out` carries the pin of the default-branch read only when the read was approved and gave the profile (`with_definition` applied). A profile that then fails §11.3 still records the pin: later starts give the same §11.3 line from the same bytes.
- D5. `first_pin` sets `launch.definition` only when it is `None`, in both start writes (ws run: after `record_start`; hand start: after `hand_join`, on the written record). A saved pin is never replaced.
- D6. A hand resume (R§7.4 bullet 2 as rewritten): `hand_start` sets the context launch's `definition` to `kept_pin(…)`, and `launch_hand` copies it into `opts.definition`. When the record is no longer kept under the lock, `join` makes a new record from that launch, which then holds the pin that the launch used.
- D7. Tests. The launcher tests L1-L11 run in process in CI with the injected runner, as WD-13's `crates/zygo-launch/tests/repo_profile.rs` does. The binary tests that launch the stub agent (B1-B5) carry `#[ignore = "timing: the agent launch has 2 s launcher probes"]` and the tmux tests (E1-E3) `#[ignore = "timing: tmux e2e: 2 s tmux calls, 2 s launcher probes and lock waits"]`, the attributes of `workspace_run.rs:366` and `workspace_restore.rs:339` (global constraint: no deadline test in CI). /// `<root>/app`: a clone of the bare `<root>/o.git`, whose `main` holds `files` (paths from the repository root),
/// so `refs/remotes/origin/HEAD` is `refs/remotes/origin/main` (R§18 preamble).
fn repo_at(root: &Path, files: &[(&str, &str)]) -> PathBuf {
    let w = root.join("w");
    std::fs::create_dir_all(&w).unwrap();
    for (path, body) in files {
        let p = w.join(path);
        std::fs::create_dir_all(p.parent().unwrap()).unwrap();
        std::fs::write(p, body).unwrap();
    }
    git(root, &["init", "-q", "--bare", "-b", "main", "o.git"]);
    git(&w, &["init", "-q", "-b", "main"]);
    git(&w, &["add", "-A"]);
    git(&w, &["commit", "-q", "-m", "c"]);
    git(&w, &["remote", "add", "origin", "../o.git"]);
    git(&w, &["push", "-q", "origin", "main"]);
    git(root, &["clone", "-q", "o.git", "app"]);
    root.join("app")
}

/// The workspace id of `app`, from the common dir that the launcher's own `checkout` finds.
fn ws_id(app: &Path) -> String {
    workspace_id(&checkout(app, Instant::now() + Duration::from_secs(3600)).unwrap().common_dir)
}

/// Approves the default branch's files of `app` when they are not approved yet; returns the pin of the approved read.
fn approve(app: &Path, approvals: &Path) -> Pin {
    let id = ws_id(app);
    if let Use::NotApproved { digest, .. } = check_default(app, &id, approvals, &SystemGit) {
        approve_workspace_in(approvals, &id, &digest).unwrap();
    }
    match check_default(app, &id, approvals, &SystemGit) {
        Use::Approved { pin, .. } => pin,
        other => panic!("not approved: {other:?}"),
    }
}

/// Commits `.zygo/profiles/rust.toml` = `body` in `app` and pushes it to `main`: the default branch moves.

    git(app, &["add", "-A"]);
    git(app, &["commit", "-q", "-m", "change"]);

}

/// R§18 item 16: makes `pinned` unreachable in `app` (an orphan commit with `NEWER` becomes `main` and `origin/main`),
/// expires the reflogs and prunes; asserts that `app` no longer has `pinned`.
fn prune(app: &Path, pinned: &str) {
    git(app, &["checkout", "-q", "--orphan", "gone"]);
    std::fs::write(app.join(".zygo/profiles/rust.toml"), NEWER).unwrap();
    git(app, &["add", "-A"]);
    git(app, &["commit", "-q", "-m", "orphan"]);
    git(app, &["update-ref", "refs/remotes/origin/main", "HEAD"]);
    git(app, &["branch", "-q", "-f", "main", "HEAD"]);
    git(app, &["checkout", "-q", "main"]);
    git(app, &["branch", "-q", "-D", "gone"]);
    git(app, &["reflog", "expire", "--expire=now", "--all"]);
    git(app, &["gc", "-q", "--prune=now"]);
    let o = std::process::Command::new("git").arg("-C").arg(app).args(["cat-file", "-e", pinned]).output().unwrap();
    assert!(!o.status.success(), "the pinned commit {pinned} is still in the repository");
}
