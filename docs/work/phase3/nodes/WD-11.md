### Decisions (author's calls)

1. Lines R§10 does not spell out (R§17 item 3): invalid `zygo: this repository's workspace files (<full ref>) are invalid (<why>); nothing from them was applied` (an invalid read has no digest, `check.rs:30`); unread `zygo: this repository's workspace files are unread (<why>); nothing from them was applied`; `--loadout repository` with approved profile files only: `zygo: this repository's workspace files at <full ref> have no .zygo/workspace.toml; nothing started`. `<full ref>` and `<why>` pass `esc`, as in `doctor.rs:273-283`.
2. A user `default_loadout = "repository"` is an explicit choice, as `--loadout repository`: its failures exit 1.
3. With a user `[loadout.repository]`: an explicit `repository` plans it with no read; the default choice reads once and plans it only when the read is `Approved` with `workspace.toml` (`Applied.loadout_shadowed`); a read that is not approved, invalid or unread gives `solo` and the line, so content that is not approved chooses nothing.
4. The tests are not `#[ignore]`: `tests/up.rs` ignores its stand-in tests as timing (`tests/up.rs:453`), but the Phase 3 tests that run git under the same bounds run in CI (`crates/zygo-config/tests/repo_def_check.rs`, `crates/zygo/tests/definition_doctor.rs`, 0 ignored), and an ignored suite would make the acceptance command pass with no test run. No test asserts a duration.
5. The stand-in tmux is `gone_tmux` (`tests/up.rs:81-89`): `new-session` fails, the session check says gone, so `up` runs the undo (`up.rs:1278`). The test reads the step 8 write in the `before_undo` hook (`up.rs:1212`; hook API `up.rs:135`). A plan that passes step 7 ends `(1, "", "zygo: tmux: no server running on /tmp/zygo-none/s\n")` (as `tests/up.rs:1708-1710`).
6. The four `UpOpts` literals outside Files get the two new fields (`tests/up.rs:115`, `tests/up_all.rs:188`, `tests/down.rs:490`, `tests/down.rs:615`); Rust needs every field.
7. `UpOpts` drops `Debug` from its derive (`up.rs:66`): `dyn GitRunner` has no `Debug`, and no code formats `UpOpts`.
8. M-C6 is on the Spec line but its spec file is not in Files; WD-11 leaves it.

### The choice (W§8.1 step 7, first case)

`name` = `opts.loadout`, else `opts.config.workspace.default_loadout` when `opts.default_loadout_set`, else none. `explicit` = `name.is_some()`.

| Case | Result |
|---|---|
| `name` is `Some(n)`, `n != "repository"`, or the config has `[loadout.repository]` | `loadout::resolve(&opts.config, Some(n), ..)`; no read |
| Otherwise: one `check_default(&t.main_root, &t.id, &opts.paths.approvals_file, git)` | below |
| `Approved`, `def.workspace` is some, user `[loadout.repository]` (`loadout_shadowed`) | `resolve(&opts.config, Some("repository"))`, no pin |
| `Approved`, `def.workspace` is some | `resolve_repository(&cfg.loadout["repository"], &pin, ..)` on the config after `apply_to_config`, then the member maximum |
| `Approved` or `NotApproved`, no `workspace.toml`, not explicit | `solo`, no line |
| `Approved`, no `workspace.toml`, explicit | exit 1, decision 1 line |
| `NotApproved` / `Invalid` / `Unread`, not explicit | `solo` and the line on `err` |
| `NotApproved` / `Invalid` / `Unread`, explicit | exit 1 with the same line |
| `Absent`, not explicit | `solo`, no line |
| `Absent`, explicit | exit 1, `zygo: this repository has no workspace files at <full ref>` |
