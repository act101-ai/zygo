### Drift and decisions (cited)

- D1. `branch::push` already takes the lease (`branch.rs:390-401`), and `MOVED_TEXT` (`branch.rs:20`) holds `"stale info"`, git's text for a failed lease. So a failed lease is `Pushed::Moved`, which `prune::run` maps to `LeaseLost`. No new git text.
- D2. `prune::run` cannot know if the prune is due (it takes no count or flag). `Pruned::NotDue` is the value of the step-16 helper `prune_step` in `sync.rs`; `prune::run` never returns it.
- D3. "Own ack" with more than one own host (S§7.5): `prune_step` takes the longest valid own ack of this identity in the base. Each ack file is one file with one limit (S§7.4), so the longest is the one that reaches 100 000 first.
- D4. `Opts { prune: true }` forces the prune of the first pass only (as the public check, `sync.rs:239-241`). A later pass of the same sync prunes only when due.
- D5. An acknowledged entry `<addr>/<ULID>.json` that is a tree (a hostile entry, acked by S§8.5) is not removed: `update-index --force-remove` of that path removes nothing under it, so `removed` counts non-tree entries only. No message is lost by this.
- D6. A push that is neither accepted nor a failed lease returns `Err(BranchError::Git(RunError::Failed, "push"))`; the pass stops with check `push` (`branch_check`, `sync.rs:117-125`). The spec names only the lease failure (S§9); this is the same class as S§8.3 step 15 "any other error".
- D7. The step-16 prune does not move `refs/remotes/<remote>/<branch>`: S§9 does not ask for it, and the next fetch is a `+` refspec (S§6.5).
- D8. No integration test makes the own ack pass 100 000 entries: an own ack lists only ULIDs that this host imported (500 per pass, S§8.5) and a hand-written own ack is a twin (S§7.5). `due` is tested at 100 000 and 100 001; the wiring is `prune_step` (Task 3).
- D9. The test harness `common::home()` sets `HOME`, `XDG_CONFIG_HOME`, `GIT_SSH_COMMAND` (`tests/common/mod.rs:59-66`); that is the existing harness. The new tests set no variable of the process; `edit_tip` sets `GIT_INDEX_FILE` on its child `git` only.

fn grow(repo: &Path, refname: &str, n: u64) -> String {
    let o = plain(repo).args(["rev-parse", "--verify", "-q", refname]).output().unwrap();
    let from = String::from_utf8(o.stdout).unwrap().trim_end().to_string();
    let mut s = String::new();
    for i in 0..n {
        s.push_str(&format!("commit {refname}\ncommitter t <t@t.invalid> {T0} +0000\ndata 0\n"));
        if i == 0 && !from.is_empty() {
            s.push_str(&format!("from {from}\n"));
        }
        s.push('\n');
    }
    git_in(repo, &["fast-import", "--quiet"], s.as_bytes());
    git(repo, &["rev-parse", refname])
}

struct Clock(u64);
impl env::Clock for Clock {
    fn now(&self) -> SystemTime { UNIX_EPOCH + Duration::from_secs(self.0) }
}

struct Says(Verdict);
impl env::Probe for Says {
    fn probe(&self, _: &str) -> Verdict { self.0.clone() }

type HookFn = Box<dyn FnMut(&'static str) -> Result<(), Crash> + Send>;
/// The test seam: a closure called at each named point.
struct Hook(Mutex<HookFn>);
impl Hook {
    fn none() -> Hook { Hook::new(|_| Ok(())) }
    fn new(f: impl FnMut(&'static str) -> Result<(), Crash> + Send + 'static) -> Hook { Hook(Mutex::new(Box::new(f))) }
    /// `Err(Crash(point))` at the first call at `point`.
    fn crash_at(point: &'static str) -> Hook {
