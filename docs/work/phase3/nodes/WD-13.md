### Author's calls

- **Unread.** R§6.1 says an unread read counts as absent with one stderr line, and fixes no launcher text. The line, in place of the not-found line: `zygo: profile <n>: this repository's workspace files were not read (<why>); launching without it` (the form of the R§8 invalid line).
- **Files without the name.** An approved or not-approved read whose definition has no profile `<n>` gives the existing `zygo: profile <n> not found; launching without it`: the R§8 not-approved line says the profile "is in" the files, which is then false. Absent and no checkout give the same line.
- **Passthrough** prints no line: R§8 fixes none for the launcher (the `up` line of R§18 item 15 is WD-12's).
- `<why>` passes through `zygo_core::esc`, as `doctor.rs` does for the same value; it does not escape `\`, so the already escaped key path is unchanged.
- The test hook `LaunchOpts.top` gives no common dir, so a launch with that hook does no repository read (the not-found line). Only tests set it.
