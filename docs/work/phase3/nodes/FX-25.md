**Decision: "the current checkout" of `zygo up`** (R§10 row): from a work tree or any subfolder of it, `Checkout.top` of `zygo_work::repo::checkout(cwd)` (the `rev-parse --show-toplevel` of the folder); from a bare repository's own folder (or a `.git` folder), the checkout of its main worktree, which `find_checkout` already takes (`up.rs:371`) and approve uses too; by `<name>`, the saved `main_root` (no checkout is looked up from the cwd, W§8.1 step 3). The id stays `workspace_id(&co.common_dir)` (`up.rs:463`); by name it stays the state's id.

**Decision: the exits of `find_checkout`** (W§8.1 step 3):

| Where | Result | `Exit` |
|---|---|---|
| probe list in the cwd (when `checkout(cwd)` is `None`) | `Err(ListError::NotARepository)`, or `Ok` with an empty list | `{ code: 2, message: NOT_A_REPO }` |
| same | `Err(ListError::Failed)`, `Err(ListError::TimedOut)`, `Err(ListError::NotFound)` | `{ code: 1, message: <that error's Display> }` |
| same | no non-bare entry | `{ code: 2, message: BARE }` (unchanged) |
| `checkout(&main.path, deadline)` is `None` | — | `{ code: 1, message: format!("no checkout at the main worktree {}", main.path.display()) }` |
| list of the found checkout (`up.rs:374`) | any `Err` | `{ code: 1, message: <Display> }`; `NotARepository` gives the `Failed` text (after `rev-parse` found the checkout, an absent answer is a failed read, as `repo.rs:483`) |

A code-1 message has no `zygo:` prefix and is not escaped: each caller adds its prefix and escapes (approve `workspace_approve.rs:73`, loadout `loadout.rs:311`, and `preflight`, step 3).
