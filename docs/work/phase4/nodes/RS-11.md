**Spec:** docs/specs/2026-11-25-client-model-design.md K§6.4.3 (the top-level `text` rule, request obligation 11 (rewritten by this node's planner, author's call), stream obligation 2); base spec `docs/specs/2026-11-18-zygo-design.md` §7.6 facts table (`structured_output = none` row)
