Code queries, code-health analysis and sequestered secrets for AI agents

Usage: act-lite [OPTIONS] <COMMAND>

Commands:
  query    Query code structure and symbol relationships
  mcp      Model Context Protocol server
  env      Sequestered secrets: import/add/rm/run/get/list/mv (values never enter logs)
  analyze  Analyze a repository: findings with their evidence, as one JSON object
  help     Print this message or the help of the given subcommand(s)

Options:
      --format <FORMAT>
          Output format

          Possible values:
          - json: Machine-readable JSON output (default)
          - text: Human-readable, indented output
          
          [default: json]

      --workspace <WORKSPACE>
          Set workspace root explicitly

      --disable-lsp
          Disable LSP servers (LSP is enabled by default)
          
          [env: ACT_LITE_DISABLE_LSP=]

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version
